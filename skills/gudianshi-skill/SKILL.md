# 古典式 skill

一种给口播和文章配图的视觉语言：**底下是版画／旧纸的质感，上面插一个纯色、硬边、只属于屏幕时代的现代元素**。图是讲述的形象化，不是讲述的替代品。

**输出格式只有 SVG**。不输出 PNG、JPG、HTML 页面、React 组件，不给生图模型写 prompt，也不建议用户改去 PS 拼贴。所有质感都用 SVG 原生手段（pattern 排线、路径、渐变暗角）实现。

## 一、三条总原则

**1. 古典层负责质感，现代层负责刺。**
古典层：密排斜线、交叉排线、旧纸底色、暗角、尖拱、铠甲、钱币、台阶、天平以外的古器物。
现代层：纯色填充、硬边、零笔触、零阴影、零做旧。两层之间绝不做羽化或渐变过渡。

**2. 刺要占据古典物件的语义位置。**
现代元素不是「贴上去」的，它要继承原本那个位置的功能：箭的位置换成飞镖和发送图标，镜子的裂缝里长出点赞，火焰墓穴里躺着手机。先问画面里哪里有一个「空位」（被指向的、被捧着的、被供奉的、被注视的、唯一的光源），再决定刺放在哪。

**3. 图不替代说话的人。**
画面里保留图像离不开的字：年份、数字、百分比、单位、坐标轴刻度、极短的分类标签（两三个字）。

另外**最多允许 1–2 行说明文字**，但只能陈述事实，用来交代图里的数据或对象是什么：
- 可以：`1991 年起：民间借贷利率上限 = 银行同类贷款利率 × 4`、`数据：国家统计局，16–24 岁，不含在校生`
- 不可以：观点、判断、修辞、设问、结论（`进步只是幻觉`、`尺子一直在动`），以及从稿子里摘的原话

说明文字的排版：放在画面左下或右下角，字号 22–28px，墨色 `opacity 0.6–0.7`，不加底色块，不加粗。两行就是上限，写不下就删到能写下。

**不放**：标题、副标题、观点句、底部字幕条。凡是口播里会说出来的句子，图里都不写。

## 二、色板（只有一个强调色）

| 用途 | 色值 |
|---|---|
| 旧纸底色 | `#E8E2D4` |
| 墨色（线、字、纯黑刺） | `#14110E` |
| 现代面底色（略亮、略冷） | `#EFEAE0` |
| 唯一强调色：警示红 | `#B03A2E` |

红只给「关键的那一个」：关键数据点、刺上的角标、被换位的那个词。一张图里红色出现的对象不超过两处。

## 三、刺的选择

必须是**只能存在于屏幕上的东西**。汽车、电灯、西装不算——它们只会像穿帮。

可用：光标、点赞手、红点角标（带数字）、蓝色认证勾、加载圈、进度条（卡在某个百分比）、开关、滑块、带八个控制点的选中框、拼写错误红波浪线、「内容无法显示」灰块、二维码、复选框、App 图标九宫格、卡片 UI、网格底。

规则：
- **一张图只放一个刺**（一组算一个，比如点赞手 + 它的角标）。两个就变装饰。
- **刺通常要小**。小的硬物在大片柔软里，比大的更暴力。
- 刺放在**视觉动线的终点**：人物视线所指、手所指、光照到的地方。
- 读数工具优于裁决工具：用杆秤、尺、水位尺、刻度盘表达「标准在变」；**不要用天平**（天平暗示有固定砝码，会替反方说话）。

## 四、构图模板

| 代号 | 结构 | 适合 |
|---|---|---|
| A 对切 | 画面左右对切，左版画右网格，中间一条虚线；同一个物件骑在分割线上，两边画法完全一致 | 「同一件事，两个时代两种判决」 |
| B 真假两条线 | 真实数据用粗红线 + 空心圆点；「人们以为的样子」用灰色虚线，不加标注 | 打破「一路进步」叙事的数据 |
| C 对照栏 | 左右两栏，同一个词在两边出现在不同位置，红箭头表示换位 | 价值排序的变化 |
| D 被压扁 | 三级带排线的台阶，一根纯黑横杠压下，右侧出现一个纯黑块 | 多层结构被简化成一层 |
| E 递减条 | 横条长度和排线密度同步递减，最后一条变成纯红短块 | 速度越来越快 |
| F 人物 + 对象 + 刺 | 古典人物（剪影 + 版画质感）面对一个对象，刺附在对象上 | 同一对象，古今反应相反 |

## 五、数据图的硬要求

- **所有点必须用同一个比例尺算坐标**，先写出映射公式再画（例：0% → y740，61.2% → y200，k = 8.824 px/%）。
- 数字必须核实过才能上图；不确定的数据不画。
- 保留坐标轴和刻度（这是解释性数字，应当保留）。
- 非等比例的示意图（例如 800 年对 5 年），交付时要向用户说明「这是示意，不按比例」，或改用对数刻度。

## 六、字体

- 古典层：`'Songti SC','Source Han Serif SC','Noto Serif CJK SC',serif`
- 现代层：`'PingFang SC','Source Han Sans SC','Noto Sans CJK SC',sans-serif`
- 数字：`'Menlo','Courier New',monospace`
- 年份和大数字可以很大（90–100px），标签 30–50px，刻度 22–26px。

## 七、SVG 技法片段

```xml
<!-- 版画斜排线 -->
<pattern id="h1" width="6" height="6" patternUnits="userSpaceOnUse" patternTransform="rotate(45)">
  <line x1="0" y1="0" x2="0" y2="6" stroke="#14110E" stroke-width="2.2"/></pattern>
<!-- 反向细排线，叠加成交叉排线 -->
<pattern id="h2" width="9" height="9" patternUnits="userSpaceOnUse" patternTransform="rotate(-45)">
  <line x1="0" y1="0" x2="0" y2="9" stroke="#14110E" stroke-width="1"/></pattern>
<!-- 版画金属（深底浅线）：盔甲、剑、盾 -->
<pattern id="mt" width="7" height="7" patternUnits="userSpaceOnUse" patternTransform="rotate(38)">
  <rect width="7" height="7" fill="#14110E"/>
  <line x1="0" y1="0" x2="0" y2="7" stroke="#E8E2D4" stroke-width="1.15" opacity="0.5"/></pattern>
<!-- 现代网格底 -->
<pattern id="grid" width="40" height="40" patternUnits="userSpaceOnUse">
  <path d="M40 0H0V40" fill="none" stroke="#14110E" stroke-width="0.6" opacity="0.35"/></pattern>
<!-- 暗角 -->
<radialGradient id="vig" cx="50%" cy="50%" r="62%">
  <stop offset="60%" stop-color="#fff" stop-opacity="0"/>
  <stop offset="100%" stop-color="#14110E" stop-opacity="0.55"/></radialGradient>
```

排线的密度就是明暗：同一种 pattern，用 `opacity` 0.35 / 0.6 / 0.85 做出三档灰。越重要、越「古」的部分越密。

## 八、禁止

- 复制任何现成画作或受版权保护的角色。古典层一律用原创的 SVG 剪影和排线画出来。
- 在 SVG 里嵌入位图（`<image>` 引用 PNG/JPG 或 base64）。
- 给现代元素加阴影、描边光晕、噪点、做旧、半透明。
- 羽化两层交界。
- 第二个强调色。
- 标题、观点句、字幕条；超过两行的说明文字。

## 九、交付

1. 先读稿子，列出最值得视觉化的 3–6 个论点，每个对应一个构图模板。
2. 每张 1600×900 的独立 SVG 文件，写入输出目录下的 `imgs/`（claude.ai 是 `/mnt/user-data/outputs/imgs/`，Claude Code 是当前工作目录的 `imgs/`），文件名 `序号_论点关键词.svg`。只交付 SVG，不附带其他格式。
3. 交付时每张只用一两句说明：对应稿子哪一段、刺是什么、为什么放在那。
4. 顺带说明任何非等比例或未核实的数据。
