# 穿衣档案

人的信息只收一次，整理成一张卡，以后每件衣服都用它。

## 怎么收

先从照片看，照片看不出来的才问。每轮最多问 2 个，先问会改变结论的。

| 项 | 先看 | 看不出来再问 |
|---|---|---|
| 颜色 | 自拍：自然光、不开美颜、素颜最好 | 金饰和银饰，哪个戴着更显气色？晒了以后先变红还是先变黑？纯白和米白的 T 恤，哪件穿着脸更干净？ |
| 身高 | — | 必问，判断长度落点要用 |
| 线条 | 全身照：站直、正面、穿贴身一点的衣服 | 肩和胯哪个宽？腰细的地方明显吗？上身和腿，哪段显得长？ |
| 气质 | 自拍和全身照：骨架和五官大小、轮廓圆润还是有棱角 | 一般不问，看不出来就在档案里写「待定」 |
| 场合 | — | 这件打算什么时候穿？一周大概几天上班、几天休息？ |
| 衣橱 | — | 最常穿的三四件是什么？ |
| 方向 | — | 想往什么方向穿？有没有绝对不碰的？ |
| 合身尺寸 | — | 选填，问尺码时再要：拿一件穿着最合身的同类衣服平铺量（外套量肩宽、胸围、衣长、袖长；裤子量腰围、裤长、大腿围、脚口） |

不要一次把表里的问题都抛出去。用户只想快速问一件，就先判断这一件，档案慢慢补齐。

**合身尺寸**比身高体重好用：它是衣服的尺寸，能直接和商品的尺码表一项一项对（见 `line.md` 的尺码）。同一项可以记一个范围（比如肩宽 38～39），也可以记一句经验（比如「衬衫胸围 100 以下才修身」）。

照片的坑（光线、美颜、妆、染发）见 `color.md`，有这些情况就把颜色那一项的可信度往下调。

## 档案卡

第一次完整判断之后，整理成这张卡发给用户，提醒用户存下来：下次直接贴过来；用的 AI 有记忆功能的话，让它记住。

```
【我的穿衣档案】
颜色：偏冷、偏浅、偏柔，对比中（可信度：中。依据：自拍，加上戴银饰更显气色）
身高：162
线条：肩和胯差不多宽，腰线明显，腿比上身长
气质：量感小，偏直，偏静
常穿场合：通勤一周五天，周末看展、逛街
衣橱里常穿：白衬衫、黑色直筒西裤、浅色牛仔外套
想要的方向：更利落一点
不碰：短裙、亮片
合身尺寸（平铺量的成衣尺寸）：外套肩宽 38～39，衬衫胸围 96 左右，裤长 95，裤子大腿围 54 以上
```

- 看不出来的项写「待定」，不要编。
- 以后的判断里发现档案和实际对不上（比如试衣照里银色反而压气色），在结论卡后面提一句「档案里这条可能要改」，给出改法。
