# 按品类判断尺码和长度

不同品类，「合身」的标准不一样：夹克要短，西装要盖住臀部，半身裙要避开小腿最粗的地方。判断版型和尺码时，**先认出是哪个品类，按这里那一类的标准判**；这里没写到的，再用 `line.md` 的通用落点表和尺码规则。

每一类写几样：先看尺码表上哪几个数、长度落在哪、怎么算合身、风格和正式度、做工看哪、常见的坑。数字都从商品尺码表读（见 `product-input.md`），和用户**同一品类**的合身尺寸比：西装和合身的西装比，夹克和合身的夹克比，不拿 T 恤的数去比西装。

下面的「净 + 几厘米」是在净体尺寸（量身体）上加的放松量，都是粗估；用户有同品类的合身尺寸时，以合身尺寸为准。

## 速查

| 品类 | 先看的数 | 长度落在哪 |
|---|---|---|
| T 恤 | 肩宽、胸围、衣长 | 胯骨到臀中；oversize 可到臀下沿 |
| 衬衫 | 领围、肩宽、胸围、袖长、衣长 | 塞着穿：盖住臀部；不塞：胯骨到臀中 |
| 针织衫、毛衣 | 胸围、衣长、袖长 | 盖住裤腰、到胯骨；罗纹下摆别卡在胯最宽处 |
| 卫衣 | 胸围、衣长 | 胯骨到盖住臀部 |
| 夹克、皮衣 | 衣长、肩宽、胸围、袖长 | 腰带到胯骨，偏短 |
| 西装外套 | 肩宽、胸围、衣长、袖长 | 盖住臀部 |
| 大衣、风衣 | 衣长、肩宽、胸围、袖长 | 短款盖臀到大腿中段上方，长款膝盖上下或小腿下段 |
| 羽绒服、棉服 | 胸围、衣长 | 短款到胯骨，长款到膝 |
| 马甲、背心 | 衣长、胸围 | 刚好盖住裤腰 |
| 西裤 | 腰围、前浪、臀围、大腿围、膝围、裤长、脚口 | 裤脚碰不碰鞋面 |
| 牛仔裤、休闲裤 | 腰围、前浪、后浪、大腿围、脚口、裤长 | 按裤型和风格 |
| 短裤 | 腰围、大腿围、裤长 | 大腿中段到膝上 |
| 半身裙 | 腰围、臀围、裙长 | 避开大腿中段和小腿最粗处 |
| 连衣裙 | 肩宽、胸围、腰围、衣长 | 裙摆照半身裙；腰线对上人的腰 |
| 鞋 | 脚长、楦型 | — |

## 上装

### T 恤

- **长度**：不塞的时候落在胯骨到臀中；oversize 款可以到臀下沿，再长就成了短裙的比例。要塞进去穿的，衣长要够塞，抬手不出来。
- **合身**：正肩款肩缝在肩骨上；胸围比合身的 T 恤大太多，就是换了一种廓形，要按 oversize 判，别按大一码判。
- **领口**：领口大小要和头成比例，头和脸量感大的，领口别太小。
- **坑**：纯棉下水会缩，尤其是衣长；薄款贴身会显出里面的轮廓。

### 衬衫

- **领围**：扣上最上面一粒，能伸进一两根手指。和合身衬衫的领围比，差 1 厘米就有感觉。
- **胸围**：净 +8～10 修身，+10～12 合体。修身的显得干练，也方便外面再穿一层。
- **袖长**：解开袖扣、手臂下垂，袖口在虎口上方 1 厘米左右；扣上，袖口过手腕 2 厘米左右；手往前伸，袖口还在手腕附近。要穿在西装里的，比西装袖长出 1～1.5 厘米。
- **长度**：要塞进去穿的正装衬衫，衣长要盖住臀部，抬手、弯腰不从裤腰里出来；下摆平、到胯骨的休闲衬衫是设计成不塞的，塞进去会不够长。
- **领型决定形象**：小领（小方领、八字领、伊顿领、软领座的小领）内敛、书卷气、有亲和力；长尖领、温莎领、意式大尖领商务、有压迫感；古巴领、一片领张扬、休闲。中等大小的八字领最不挑人和场合。
- **一致**：领面大小、袖克夫高度、领带宽度、西装驳头宽度要差不多一致。领子很小、袖克夫很高，就不协调。
- **面料决定正式度**：丝光棉、高支府绸正式；牛津纺、法兰绒、牛仔布、亚麻、灯芯绒休闲；莫代尔、天丝显得随性，不适合正式场合。**休闲面料别配正装的版型**：亚麻配高领座、尖领型，不伦不类。
- **西部衬衫**和绅装的牛仔衬衫不是一回事：西部衬衫衣长偏短、胸围偏宽、领口大、领座低、有育克和袋花，偏休闲。
- **做工**：领子和门襟是最先被看到的地方；走线每英寸 14 针起码，11 针就粗了；好的扣子有绕脚、离面料有一点距离；领衬好的领子洗多次不塌，差的洗后会扭。
- **坑**：150 支、200 支的高支棉很容易皱；白衬衫克重低于 130 左右容易透；白色的棉和亚麻容易发黄；液氨免烫的衬衫第一次先洗再穿。

### 针织衫、毛衣

- **长度**：套头款盖住裤腰、落在胯骨附近；罗纹下摆会收在那里，卡在胯最宽处会更显宽。要穿在西装、夹克里面的，衣长不能比外套长。开衫照外套看。
- **合身**：针织有弹性，尺码表上的胸围和身体差不多也能穿，是贴身的效果；想要松一点再往上加码。袖长可以略长，堆在手腕上。
- **量感**：粗针、绞花、大落肩的膨胀款量感大，适合上身单薄、想加点分量的；上身本来就有分量的（肩宽、背厚、脖子短），选正肩或插肩、V 领或大一点的圆领，要么轻薄垂顺，要么修身。
- **领口**：圆领显得亲和；高领显得书卷、知性；V 领拉长脖子。圆领毛衣里面可以配小方领、圆领的衬衫。
- **面料**：羊毛、马海毛、羊绒占七成以上，再混一到三成粘胶、醋酸、莱赛尔、真丝的，手感好、不太起球、好打理；以腈纶、聚酯为主的不推荐；纯棉毛衣洗后会发硬。
- **做工**：对着光看，织得稀、透光的是在省料。
- **坑**：羊毛、羊绒、混纺会起球、掉绒；多数只能手洗或干洗，洗羊毛不加柔顺剂容易发硬。表上的「胸围」可能是按身体写的，用试穿表核一下（见 `product-input.md`）。

### 卫衣

- **长度**：胯骨到盖住臀部；罗纹下摆的同样别卡在胯最宽处。
- **合身**：多数是落肩，肩宽大是设计，看胸围和衣长（见 `line.md` 的肩线）。
- **坑**：加绒款更厚，量感更大；帽子的分量会把重心往上带。

### 夹克、皮衣

短夹克、工装夹克、牛仔夹克、皮夹克、飞行夹克、哈灵顿夹克、机车夹克、猎装夹克都算。

- **长度**：要偏短，落在腰带到胯骨之间，腿才显长。男款：个子越高可以越长，但衣长一般不超过 63；175 以下的，60 以内。女款落在腰到胯骨。超过这个范围，就不再是夹克的比例。
- **袖长**：也要偏短，到腕骨；长了盖住手背就拖沓。罗纹收口的飞行夹克，罗纹会把多出来的量收住。
- **合身**：正肩款肩宽和合身的夹克差 1 厘米以内；胸围要留出里面穿一件毛衣或卫衣的余量。
- **搭配**：短而有力量感的夹克，下面配量感大一点的裤子（宽松直筒、弯刀裤）。
- **做工**：下摆应该平直或微微收，往里凹是剪裁有问题；牛仔和皮夹克的明线，粗的撞色线显得饱满、结实，同色细线容易呆板。
- **皮衣**：牛皮、马皮耐用，羊皮最软但不耐磨，鹿皮兼顾柔软和强度；会随穿着变软、略微撑开，买的时候可以偏贴身；黑色内搭最稳；不能水洗，用毛巾擦、阴干；茶芯皮会掉色露底，是特点不是瑕疵。
- **坑**：工装夹克面料硬，肩和胸更不能紧；猎装夹克后背有活褶，是为了手臂往前活动。

### 西装外套

- **胸围**：净 +6～8 修身，+9～11 合身，+12 以上偏宽松。扣上（两粒扣扣上面那粒）前胸不出现 X 形拉褶，前胸和扣子之间大约能放进一个拳头；里面要能穿衬衫或薄针织。
- **肩**：最要紧，改不了。肩缝略超出肩骨，肩线平顺，垫肩的边不塌、不翘、不顶出一个台阶；和净肩宽差 1.5 厘米以内都能接受，夹在两码之间以胸围为准，英式带垫肩的可以再宽一两厘米。见 `line.md` 的肩线。
- **长度**：要盖住臀部，偏长没问题，偏短才是问题（短到露出臀部，比例就成了夹克）。手臂自然下垂、手指微微弯起，能摸到下摆，是传统的长度；粗估是身高 × 0.4 + 5。现在流行略短，差一两厘米都能接受。尺码表写「后中长」的，和合身西装的后中长直接比。
- **袖长**：到手腕骨下 1 厘米左右，露出衬衫袖口 1～1.5 厘米。袖长能改，肩不能改。
- **前后平衡**：站直时前下摆、后下摆都不翘，后背中间不堆量；后领贴着脖子，不空出一截。
- **比例是联动的**：肩加宽，衣长也要跟着加长，不然成了一块方砖；扣位降低，衣长也要加长。看 oversize 西装时，肩宽、衣长、扣位一起看。
- **扣位、串口、驳头**：扣位低、贴袋、船型胸袋、串口低，视觉中心往下走，更休闲、更松弛，也更压个子；扣位高、串口高更利落、更正式、更凌厉。驳头宽度要和脸、肩、领带、衬衫领成比例。袖窿高，抬手时西装不跟着往上跑。
- **面料定性质**：精纺纯色、鸟眼、细条纹、暗格、暗人字是套装面料，上下同色就是正装；明显的大格、明显的人字纹、杂色粗花呢、枪会格是单西面料，偏休闲；亚麻、泡泡纱、棉、毛麻丝、灯芯绒两种都能做。纯色灰法兰绒的上衣单穿很难搭。**软面料配软垫肩，硬面料配硬垫肩**，面料和支撑要匹配。
- **颜色**：纯黑容易像制服；藏青、深灰最稳；哑光比亮面耐看。浅灰配浅色的鞋，深灰配黑鞋。
- **配牛仔裤**：选修身、下摆不长（和袖口齐平最好）、一两粒扣的；牛仔裤直筒、裤长到不在鞋面上堆叠。
- **做工**：领口翻折弧度自然、肩部圆顺无褶、口袋贴身不外翻；牛角扣、扣子有绕脚；驳头和口袋边有手工挑边（珠针）；袖扣能真的解开；全麻衬 > 半麻衬 > 黏合衬。
- **坑**：模特图里西装常在背后夹过；支数越高越娇气，120～130 支耐穿，150 支以上易皱；库存的老面料会发干、失去光泽。

### 大衣、风衣

- **长度**：短款盖住臀部到大腿中段上方；长款在膝盖上下，或者到小腿下段。个子不高的，选膝盖上方一点或膝下一掌，别落在小腿最粗处。
- **合身**：要套在西装、毛衣外面的，肩宽、胸围要比合身的西装大一点，能套进去、手往前伸不绷；袖长要盖住里面的西装袖。落肩、插肩款（巴尔玛肯、多数风衣）按 `line.md` 的肩线看。
- **坑**：风衣系上腰带会多一条腰线，腰线的位置要对上人的腰；厚呢大衣量感大，骨架小的人选薄一点、短一点的；羊绒大衣基本只能干洗，算上每年的护理费再决定。

### 羽绒服、棉服

- **长度**：短款到胯骨，长款到膝；个子不高的穿长款，同样别落在小腿最粗处。
- **合身**：填充本身占地方，胸围要比合身的外套多留；里面还要穿毛衣的再多一点。
- **坑**：填充越厚量感越大，骨架小的人选薄、短、绗线细的；亮面面料偏动、反光。

### 马甲、背心

- **长度**：刚好盖住裤腰。西装马甲不能露出裤腰和衬衫之间那一截；针织背心的下摆落在腰线或裤腰上最利落。
- **合身**：贴身穿，胸围按合身尺寸比，别大。
- **坑**：配低腰裤时，马甲和裤腰之间容易露出一截衬衫。

## 下装

### 西裤

- **围度**：腰围净 ±1～2（弹力腰另算）；臀围至少净 +6，+8 合适，+10 更舒服；大腿围净 +6 修身，+8 较宽松，再大就是廓形；膝围至少净 +6。
- **腰**：先看前浪，决定裤腰落在腰上还是胯上；高腰的腰围按净腰围比，低腰的按胯的位置比。带侧调节扣或背带扣的正装西裤，本来就不系腰带。
- **裤长**：看裤脚落在鞋面上的样子：不碰鞋面（no break）干净利落、轻轻碰出一个小褶（half break）、堆出几个褶（full break），按用户想要的说。脚口窄的可以短一点露出脚踝；宽脚口的要长一点，不要外翻。
- **裤型和量感**：锥形、小脚量感小，直筒中等，微喇中偏大，阔腿最大。锥形裤从胯往下收，视线会落在胯上；直筒、阔腿直上直下。**包住臀部、大腿内侧线条干净，裤子才显得长、显得直。**
- **细节**：前褶分无褶、单褶、双褶，双褶活动量最大；褶向内开是英式、更正式，向外开是意式、更休闲。侧兜：直兜精致，斜兜休闲（卡其裤常见），挖兜偏礼服。翻边多用在法兰绒、卡其这类休闲款上。连腰（腰头不断开）显得干净极简。
- **面料**：垂感从差到好大致是 TR（涤粘混纺）< 羊毛 < 强捻羊毛 < 真丝。TR 垂感差，但能机洗、不变形，适合出差；化纤混纺的裤线更挺、压褶更持久。
- **做工**：腰头外面有明显横痕，是腰衬差；看腰头、裤兜、珠边这些细节的车工。
- **坑**：裤长能改短，改不长；腰围能收，放的余量有限；裆深太深（拖裆）会让小腹那一段线条拖沓。

### 牛仔裤、休闲裤

- **裤型**：前浪定腰高低，大腿围和脚口定裤型：直筒、锥形、阔腿、微喇、喇叭。微喇把视线往下带，显腿长，也能盖住小腿的弯。
- **前后浪**：浪差（后浪减前浪）窄版直筒常见 10～12，阔腿 12～16，低腰 7～9。浪差大，臀部的容量大，适合臀部圆、翘的；浪差小，适合臀部扁平的。
- **不合身的信号**：卡裆，是总裆长或前浪太短；前面鼓出一块，是前浪太长；磨大腿内侧、坐下勒裆，是后浪太短。
- **线条**：后腰育克的 V 形越深，越显得提臀；侧缝线越往前，腿从正面看越窄。
- **裤长看风格**：绅装风格裁到不碰鞋面（no break），配西装时轻碰一个小褶、不堆叠；美式复古留长卷边；city boy、cleanfit 风格盖住脚面、甚至拖地。
- **配鞋**：脚口宽的（微喇、宽直筒）配鞋头有分量的皮鞋、靴子，不配鞋身瘦的板鞋；直筒偏瘦的配切尔西靴，裤脚到脚踝，不盖脚面。
- **面料**：14～15 盎司左右是常见的中厚；赤耳布边是老式窄幅织机的特征，质感厚实；没经过预缩的原色牛仔下水会明显缩，买前看卖家说明、按说明留长度；弹力面料会越穿越松。
- **坑**：黑色牛仔做旧容易发白，看着不干净，追求利落的风格要慎重；太紧的裤子更容易卡裆、勒裆。

### 短裤

- **长度**：大腿中段到膝上；裤长和大腿围一起决定是贴腿还是阔腿。
- **合身**：腰围按合身的裤子比；大腿围太紧的，走路会往上缩。
- **坑**：裤脚落在大腿最宽处时，配宽一点的裤脚。

### 半身裙

- **裙长**：迷你在大腿中段以上，及膝在膝盖上下，中长裙到小腿下段，长裙到脚踝。**避开大腿中段和小腿最粗的地方**；中长裙要么停在膝下一点，要么一直到小腿下段。用 `line.md` 的落点表（裙长那张）换算。
- **腰围**：穿在腰上的，裙腰和净腰围差不多或大一两厘米；低腰的按胯的位置比。
- **臀围**：看裙型。包臀裙、铅笔裙跟着身体走，臀围要比净臀围大一些才走得开路（粗估 4～6 厘米）；A 字裙、百褶裙、伞裙臀围很松，主要看腰围和裙长。
- **坑**：长的直筒、包臀款要有开衩才好走路；百褶、伞裙量感大，骨架小的人选褶细、长度短一点的。

### 连衣裙

- **腰线**：裙子的腰线（收腰的那条线、拼接线、系带）要落在人的腰上；高腰款落在胸下，显腿长；低腰款落在胯上，腰线不明显的人更顺。
- **合身**：肩、胸、腰三处都要合，其中一处不合就要换款，没法只改一处。
- **长度**：裙摆照半身裙的标准判。
- **坑**：一片式的连衣裙最挑上下身比例，上身长的人选高腰款；吊带款看肩带位置和胸围。

## 鞋

- **尺码**：按脚长（毫米）和楦型，不按别的鞋的码数推。脚背高、脚宽的先看楦型合不合，再看码。乐福鞋不跟脚、后跟出来，大半码的用鞋垫和后跟贴补。
- **正式度**：光面皮 > 反绒皮；黑 > 深棕 > 浅色；牛津 > 德比 > 乐福 > 靴子 > 运动鞋；鞋头素头、三接头最正式，布洛克、雕花更休闲。**反绒、浅色、圆头这些「降锐度」的处理都在降正式度。**
- **和衣服的质感对上**：粗纺、哑光的上衣（法兰绒、粗花呢）配反绒、德比、靴子，不配光面牛津鞋。西装套装换上反绒乐福或反绒切尔西靴，正式感会降一档。
- **和裤脚对上**：见上面牛仔裤的「配鞋」；西裤裤脚别在鞋面上堆一大团。
- **做工**：挪威缝、琴底 > 固特异 > 布雷克缝 > 胶粘，前两档耐穿、能换底；鞋面看皮料等级。
- **坑**：皮鞋怕水、怕晒，雨天别穿不防水的皮鞋，要定期上油护理；舒服排第一，再看好不好看。

## 腰带

- 绅装常见宽度 2.5～3 厘米；棕色反绒腰带几乎能配精纺正装以外的所有西装和单西。
- 腰带和鞋的颜色、材质往一处靠（棕鞋配棕带、反绒配反绒）。
- 正装西裤带侧调节扣的不系腰带；休闲的穿法才系。
