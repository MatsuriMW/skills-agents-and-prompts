# 按品类判断尺码和长度

不同品类，「合身」的标准不一样：夹克要短，西装要盖住臀部，半身裙要避开小腿最粗的地方。判断版型和尺码时，**先认出是哪个品类，按这里那一类的标准判**；这里没写到的，再用 `line.md` 的通用落点表和尺码规则。

每一类写四样：看尺码表上哪几个数、长度落在哪、怎么算合身、常见的坑。数字都从商品尺码表读（见 `product-input.md`），和用户**同一品类**的合身尺寸比：西装和合身的西装比，夹克和合身的夹克比，不拿 T 恤的数去比西装。

## 速查

| 品类 | 先看的数 | 长度落在哪 |
|---|---|---|
| T 恤 | 肩宽、胸围、衣长 | 胯骨到臀中；oversize 可到臀下沿 |
| 衬衫 | 领围、肩宽、胸围、袖长、衣长 | 塞着穿：盖住臀部；不塞：胯骨到臀中 |
| 针织衫、毛衣 | 胸围、衣长、袖长 | 盖住裤腰、到胯骨；罗纹下摆别卡在胯最宽处 |
| 卫衣 | 胸围、衣长 | 胯骨到盖住臀部 |
| 夹克 | 衣长、肩宽、胸围、袖长 | 腰带到胯骨，偏短 |
| 西装外套 | 肩宽、胸围、衣长、袖长 | 盖住臀部 |
| 大衣、风衣 | 衣长、肩宽、胸围、袖长 | 短款盖臀到大腿中段上方，长款膝盖上下或小腿下段 |
| 羽绒服、棉服 | 胸围、衣长 | 短款到胯骨，长款到膝 |
| 马甲、背心 | 衣长、胸围 | 刚好盖住裤腰 |
| 西裤 | 腰围、前浪、臀围、大腿围、裤长、脚口 | 裤脚碰不碰鞋面 |
| 牛仔裤、休闲裤 | 腰围、前浪、大腿围、脚口、裤长 | 按裤型 |
| 短裤 | 腰围、大腿围、裤长 | 大腿中段到膝上 |
| 半身裙 | 腰围、臀围、裙长 | 避开大腿中段和小腿最粗处 |
| 连衣裙 | 肩宽、胸围、腰围、衣长 | 裙摆照半身裙；腰线对上人的腰 |

## 上装

### T 恤

- **长度**：不塞的时候落在胯骨到臀中；oversize 款可以到臀下沿，再长就成了短裙的比例。要塞进去穿的，衣长要够塞，抬手不出来。
- **合身**：正肩款肩缝在肩骨上；胸围比合身的 T 恤大太多，就是换了一种廓形，要按 oversize 判，别按大一码判。
- **坑**：纯棉下水会缩，尤其是衣长；薄款贴身会显出里面的轮廓。

### 衬衫

- **领围**：扣上最上面一粒，能伸进一两根手指。和合身衬衫的领围比，差 1 厘米就有感觉。
- **袖长**：扣上袖口，落在手腕骨上；要穿在西装里的，比西装袖长出一厘米左右。
- **长度**：要塞进去穿的正装衬衫，衣长要盖住臀部，抬手、弯腰不从裤腰里出来；下摆平、到胯骨的休闲衬衫是设计成不塞的，塞进去会不够长。
- **合身**：肩缝在肩骨；扣上以后胸前门襟不往两边拉开。
- **坑**：领座高的会顶脖子；修身款背后常有省道或褶，看平铺图认得出来。

### 针织衫、毛衣

- **长度**：套头款盖住裤腰、落在胯骨附近；罗纹下摆会收在那里，卡在胯最宽处会更显宽。要穿在西装、夹克里面的，衣长不能比外套长。开衫照外套看。
- **合身**：针织有弹性，尺码表上的胸围和身体差不多也能穿，是贴身的效果；想要松一点再往上加码。袖长可以略长，堆在手腕上。
- **坑**：羊毛、羊绒、混纺会起球、掉绒；多数只能手洗或干洗；粗针、绞花量感大，见 `line.md` 的面料肌理。表上的「胸围」可能是按身体写的，用试穿表核一下（见 `product-input.md`）。

### 卫衣

- **长度**：胯骨到盖住臀部；罗纹下摆的同样别卡在胯最宽处。
- **合身**：多数是落肩，肩宽大是设计，看胸围和衣长（见 `line.md` 的肩线）。
- **坑**：加绒款更厚，量感更大；帽子的分量会把重心往上带。

### 夹克

短夹克、工装夹克、牛仔夹克、皮夹克、飞行夹克、哈灵顿夹克、机车夹克都算。

- **长度**：要偏短，落在腰带到胯骨之间，腿才显长。男款：个子越高可以越长，但衣长一般不超过 63；175 以下的，60 以内。女款落在腰到胯骨。超过这个范围，就不再是夹克的比例。
- **合身**：正肩款肩宽和合身的夹克差 1 厘米以内；胸围要留出里面穿一件毛衣或卫衣的余量；袖长到手腕，袖口有罗纹或扣子的可以略长一点。
- **坑**：皮夹克会随穿着变软、略微撑开，买的时候可以偏贴身；工装夹克面料硬，肩和胸更不能紧。

### 西装外套

- **长度**：要盖住臀部，衣长偏长没问题，偏短才是问题（短到露出臀部，比例就变成夹克了）。休闲款可以比正装短一点，但仍然盖住臀部。尺码表写「后中长」的，和合身西装的后中长直接比。
- **肩**：最要紧，改不了。肩缝在肩骨外一点，垫肩的边不塌、不翘、不顶出一个台阶。见 `line.md` 的肩线。
- **胸围**：扣上（两粒扣扣上面那粒）前胸不出现 X 形的拉褶；里面要能穿衬衫或薄针织。
- **袖长**：露出衬衫袖口一厘米左右。袖长能改，肩不能改，夹在两码之间按肩选。
- **坑**：模特图里西装常在背后夹过；面料（精纺、粗花呢、亚麻）对气质影响很大，见 `line.md` 的面料肌理。

### 大衣、风衣

- **长度**：短款盖住臀部到大腿中段上方；长款在膝盖上下，或者到小腿下段。个子不高的，选膝盖上方一点或膝下一掌，别落在小腿最粗处。
- **合身**：要套在西装、毛衣外面的，肩宽、胸围要比合身的西装大一点，能套进去、手往前伸不绷；袖长要盖住里面的西装袖。落肩、插肩款按 `line.md` 的肩线看。
- **坑**：风衣系上腰带会多一条腰线，腰线的位置要对上人的腰；厚呢大衣量感大，骨架小的人选薄一点、短一点的。

### 羽绒服、棉服

- **长度**：短款到胯骨，长款到膝；个子不高的穿长款，同样别落在小腿最粗处。
- **合身**：填充本身占地方，胸围要比合身的外套多留；里面还要穿毛衣的再多一点。
- **坑**：填充越厚量感越大，骨架小的人选薄、短、绗线细的；亮面面料偏动、反光。

### 马甲、背心

- **长度**：刚好盖住裤腰。西装马甲不能露出裤腰和衬衫之间那一截；针织背心的下摆落在腰线或裤腰上最利落。
- **合身**：贴身穿，胸围按合身尺寸比，别大。
- **坑**：配低腰裤时，马甲和裤腰之间容易露出一截衬衫。

## 下装

### 西裤

- **腰**：先看前浪，决定裤腰落在腰上还是胯上；高腰的腰围按净腰围比，低腰的要按胯的位置比。
- **裤长**：看裤脚落在鞋面上的样子：不碰鞋面、轻轻碰出一个小褶、堆出几个褶，是三种不同的穿法，按用户想要的说。脚口窄的可以短一点，露出脚踝。
- **合身**：臀围、大腿围坐下不绷；单褶、双褶的裤子前面有余量，站着时褶要能合上，不被撑开。
- **坑**：裤长能改短，改不长；腰围能收，放的余量有限。

### 牛仔裤、休闲裤

- **裤型**：前浪定腰高低，大腿围和脚口定裤型：直筒、锥形、阔腿、喇叭。用户想要的裤型和尺码表的数对得上，才算这一款。
- **裤长**：直筒和阔腿可以留长卷边；锥形裤脚口窄，堆多了会在脚踝挤成一团。
- **合身**：腰围按合身的同类裤子比；大腿围小了坐下绷。
- **坑**：没经过预缩的原色牛仔下水会明显缩，买前看卖家的说明，按说明留长度；弹力面料会穿松。

### 短裤

- **长度**：大腿中段到膝上；裤长和大腿围一起决定是贴腿还是阔腿。
- **合身**：腰围按合身的裤子比；大腿围太紧的，走路会往上缩。
- **坑**：裤脚落在大腿最宽处时，配宽一点的裤脚。

### 半身裙

- **裙长**：迷你在大腿中段以上，及膝在膝盖上下，中长裙到小腿下段，长裙到脚踝。**避开大腿中段和小腿最粗的地方**；中长裙要么停在膝下一点，要么一直到小腿下段。用 `line.md` 的落点表（裙长那张）换算。
- **腰围**：穿在腰上的，裙腰和净腰围差不多或大一两厘米；低腰的按胯的位置比。
- **臀围**：看裙型。包臀裙、铅笔裙跟着身体走，臀围要比净臀围大一些才走得开路（粗估 4～6 厘米）；A 字裙、百褶裙、伞裙臀围很松，主要看腰围和裙长。
- **坑**：长的直筒、包臀款要有开衩才好走路；百褶、伞裙量感大，骨架小的人选褶细、长度短一点的。

### 连衣裙

- **腰线**：裙子的腰线（收腰的那条线、拼接线、系带）要落在人的腰上；高腰款落在胸下，显腿长；低腰款落在胯上，腰线不明显的人更顺。
- **合身**：肩、胸、腰三处都要合，其中一处不合就要换款，没法只改一处。
- **长度**：裙摆照半身裙的标准判。
- **坑**：一片式的连衣裙最挑上下身比例，上身长的人选高腰款；吊带款看肩带位置和胸围。
