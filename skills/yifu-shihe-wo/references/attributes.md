# 衣服属性卡

衣服这边的坐标。人那边是穿衣档案（`profile.md`），两张卡用同一套坐标；判断就是拿属性卡一项一项对**这个用户自己的**档案。属性卡只描述衣服，不带任何人的身材。

## 什么时候用

- **每次判断前**，先照这张卡把衣服读一遍（不用每次都贴出来）。读不出来的项，就知道该请用户补哪张截图。
- 用户说「给我这件的属性卡」「帮我拆解一下这件」「这件是什么样的」「帮我记一下这件」时，按下面的模板整理出来。
- **参考图**（想找这种款）：属性卡就是「按这些数去找」的清单。
- 用户想把这件记进自己的衣橱或笔记：字段名都是通用的，直接复制。

## 模板

色卡放在最上面，下面是属性卡：

```
【色卡】
主色　🟫 燕麦色　≈ #C8B89A
辅色　⬜ 米白人字纹　≈ #E6DED0
色系　大地色 · 浅暖调
冷暖　冷 ━━━━━━●━━ 暖
明暗　暗 ━━━━━━●━━ 亮
鲜浊　浊 ━━●━━━━━━ 鲜
对比　低　　光泽　哑光

【属性卡】燕麦色粗花呢两粒扣单西
来源：商品链接（参数、详情图里的卖家尺码表、主图）　看的码：50
基本　上装 · 西装外套 · 外套层　秋、冬　男款
尺寸　肩宽 45　胸围 104　衣长 74（后中长）　袖长 61（卖家表，胸围是平铺乘 2）
颜色　燕麦色：偏暖、浅、偏浊；自身对比低；哑光
图案　细密的人字纹；尺度小
材质　羊毛 80% 羊绒 20%；梭织、粗纺斜纹；中厚；有支撑；颗粒
廓形　H、合身；肩：正肩、薄垫肩（克制）；领：平驳领、驳头中等宽；没有收腰线
细节　贴袋、船型胸袋；扣位偏低；同色明线；装饰少
坐标　量感 中偏大　曲直 中偏直　动静 静　骨架最顺：骨架感、直线型　正式度 3
风格　读起来像 Ivy、绅装（粗花呢、贴袋、燕麦色）
打理　干洗；粗纺不太显皱
缺　买家秀；袖扣是真是假看不出
```

- 每一项后面能看出来源的就写来源（尺码表、参数、详情图、主图、买家秀）；推出来的标「推断」。
- 看不出来的项写「看不出」或放进「缺」，不要编。
- 长度落在身上哪里、松量算修身还是宽松，要对用户的身高和尺寸，填卡时先只写数，判断时再算。

## 每一项怎么填

### 基本

- **类别**：上装 / 下装 / 鞋 / 腰带 / 首饰 / 包 / 配饰。
- **子类**：具体品类，对应 `categories.md` 里的那一类。
- **层次**（上装）：内搭（衬衫、T 恤、polo）/ 中层（毛衣、开衫、背心、马甲）/ 外套。
- **季节**：春 / 夏 / 秋 / 冬 / 四季，看厚薄和成分。
- 男款还是女款。

### 尺寸

从尺码表读要买的码那一行（读法见 `product-input.md`）：上装记肩宽、胸围、衣长、袖长、领围；下装记腰围、臀围、大腿围、前浪、后浪、裤长、脚口；鞋记脚长和楦型。写清量法（平铺还是周长、肩颈点还是后中长），以及这是衣服的尺寸还是身体的尺寸。

### 色卡

色卡只说**这件衣服自己的颜色**，不说和人合不合（那是判断时的事）。

- **主色、辅色**：主色是面积最大的颜色；辅色是第二种颜色、花纱里的浅色纱、明线、图案色，没有就不写。每个色写：一个最接近的色块、具体的色名、能估就估一个 ≈HEX。
  - 色块只有这几个：🟥 红、🟧 橙、🟨 黄、🟩 绿、🟦 蓝、🟪 紫、🟫 棕、⬛ 黑和深灰、⬜ 白和浅灰。挑最接近的，只是示意，色名和 HEX 才是准的。
  - 宿主能画图、能渲染 HTML 的，可以按 HEX 画真的色块。
- **色系**：色相大类（红、橙、黄、绿、蓝、紫、棕、黑白灰），加一个通用说法帮人理解：大地色、美拉德、灰调（莫兰迪）、粉彩、高饱和、黑白灰中性、海军蓝、军绿卡其。通用说法只放在色系里，色名还是要具体。
- **冷暖、明暗、鲜浊**：各画一条九格的刻度，● 落在哪格表示偏向哪边，正中间是中性。明暗就是 `color.md` 里的深浅，鲜浊就是清浊（饱和度高、干净为鲜，带灰为浊）。
- **对比**：这件自己的拼色、图案反差：低 / 中 / 高。
- **光泽**：哑光 / 微光 / 亮面。
- 颜色以买家秀为准，只有主图时在属性卡的「缺」里写上；屏幕有色差，色卡只是示意。

### 颜色

- 具体的色名（「燕麦色」「炭灰」「靛蓝」），不写「莫兰迪色」这种笼统的。
- 四个量：冷暖、深浅、清浊、对比（这件自己的拼色、图案反差），见 `color.md`。
- 光泽：哑光 / 微光 / 亮面。
- 有买家秀时以买家秀的颜色为准。

### 图案

- 类型：纯色 / 暗纹（人字纹、鸟眼、提花）/ 条纹 / 格纹 / 印花 / 织纹（绞花、罗纹）。
- 尺度：细密 / 中 / 大。

### 材质

- **成分**：照参数抄。
- **织法**：梭织还是针织；平纹、斜纹还是缎纹；精纺还是粗纺。
- **厚薄**：薄 / 中 / 厚。参考克重、牛仔的盎司、针织的针数（针数越小越粗）。
- **硬软**：挺括（自己能立住）/ 有支撑 / 垂顺 / 软塌。
- **肌理**：光滑 / 细纹 / 颗粒 / 粗粝 / 绒面。
- **弹性**：无 / 微弹 / 高弹。

常见材质看起来、摸起来是什么样（打理见 `worth.md`）：

| 材质 | 样子 | 往哪个方向推 |
|---|---|---|
| 精纺羊毛 | 有支撑、垂感好、哑光细腻 | 正式；量感小到中 |
| 粗纺羊毛（粗花呢、法兰绒） | 有支撑，颗粒或绒面 | 休闲；量感大；偏浊、偏静 |
| 羊绒 | 软、暖、微光 | 柔；量感看厚薄 |
| 府绸、丝光棉 | 挺、光滑 | 偏正式 |
| 牛津纺、牛仔、帆布、灯芯绒 | 硬朗，有纹理 | 休闲；量感中到大 |
| 亚麻 | 挺，易皱，有麻结 | 休闲、松弛；配骨架感 |
| 真丝、缎面 | 垂、亮 | 偏动、偏柔 |
| 粘胶、莫代尔、莱赛尔、醋酸 | 垂顺、凉、软 | 偏柔、偏随性 |
| 涤纶、TR | 挺还是垂看织法，光泽偏死 | 好打理，质感差一截 |
| 光面皮革 | 硬朗、反光 | 偏动；光面鞋偏正式 |
| 反绒、麂皮 | 柔、哑、绒面 | 降正式 |

同样的纤维，双股纱、双经双纬织的更挺、更抗皱、更哑光；针织比梭织软、有弹性；斜纹比平纹纹路明显、更耐磨。

### 廓形和版型

- **廓形**：H（直筒）/ X（收腰）/ A（下摆展开）/ Y（上宽下窄）/ O（中间鼓）/ I（细长直）。
- **松量**：修身 / 合身 / 宽松 / oversize。判断时拿胸围和用户同品类的合身尺寸比，或者净体尺寸加放松量（见 `categories.md`）。
- **肩**：肩型（正肩、后过肩、肩线前移、落肩、插肩、马鞍肩），强调还是弱化（见 `line.md` 的肩线）。
- **领**：领口或领型，大小（小 / 中 / 大）。
- **腰线**：高 / 自然 / 低 / 没有。
- **长度**：先记数，判断时按 `categories.md` 的品类标准换算落点。
- **裤子另记**：裤型（锥形 / 直筒 / 微喇 / 阔腿）、前浪高低、脚口宽窄。

### 细节

门襟；口袋（贴袋 / 有盖 / 嵌线，直兜 / 斜兜）；扣位高低；褶（无 / 单褶 / 双褶 / 抽褶）；明线（同色还是撞色，粗还是细）；装饰多少（少 / 中 / 多）；做旧、水洗。

### 坐标（由上面推出来）

- **量感**（小 / 中 / 大）：面料厚薄、肌理粗细、图案尺度、廓形体积、扣子和配件大小、领子和驳头宽窄。
- **曲直**（曲 / 中 / 直）：圆领、荷叶边、弧形下摆、垂坠偏曲；尖领、直线剪裁、挺括偏直。
- **动静**（静 / 中 / 动）：撞色、大图案、亮面、不对称、装饰多偏动。
- **骨架最顺**：直线型（挺括细腻、I 字、合身）/ 曲线型（轻软、收腰、上身有细节）/ 骨架感（粗粝天然、宽松、长款），见 `line.md` 的骨架。
- **正式度**（1～5）：

| 级 | 是什么 | 典型 |
|---|---|---|
| 1 | 运动、居家 | 卫衣、运动裤、拖鞋 |
| 2 | 休闲（casual） | T 恤、牛仔、工装、帆布鞋 |
| 3 | 日常精致（smart casual） | 牛津纺衬衫、针织、卡其裤、休闲单西、乐福鞋 |
| 4 | 商务（business） | 精纺单西、正装衬衫、西裤、德比鞋、牛津鞋 |
| 5 | 正装、礼服（formal） | 精纺纯色的同色套装、光面黑色牛津鞋 |

往上推的：精纺、细腻、深色、纯色或暗纹、哑光、有结构（垫肩、衬里）、视觉中心高、尖领高领座、暗门襟、嵌线口袋。往下拉的：粗纺、水洗做旧、针织、浅色亮色、大图案、贴袋、明线和撞色线、低扣位、纽扣领和古巴领、反绒、运动元素。正式度不是越高越好，和用户的场合对上才对；怎么升降一档见 `pairing.md`。

### 风格

「读起来像」哪一两种风格、凭哪几个信号，按 `styles.md` 填。

### 打理和做工

- **打理**：洗涤方式；易不易皱、起球、勾丝、缩水（见 `worth.md`）。
- **做工**：看到的做工细节（各品类看哪里，见 `categories.md`）。

## 拿属性卡对档案

| 属性卡的项 | 对档案的哪项 | 按哪份规则 |
|---|---|---|
| 颜色的四个量、光泽、离脸多近 | 颜色 | `color.md` |
| 尺寸 | 同品类的合身尺寸；没有就用净体尺寸加放松量；再没有就用身高体重粗估 | `categories.md`、`line.md` 的尺码 |
| 长度 | 身高，加上这个品类的标准 | `categories.md`、`line.md` 的长度落点 |
| 肩、廓形、腰线 | 线条（肩和胯、腰线、身高） | `line.md` |
| 量感、曲直、动静 | 气质 | `line.md` 的气质 |
| 材质硬软、廓形 | 骨架 | `line.md` 的骨架 |
| 领口、领型、靠近脸的细节 | 脸的量感和曲直 | `line.md` 的「几个坐标打架的时候」 |
| 正式度、季节 | 常穿场合 | `worth.md`、`pairing.md` |
| 读起来像 | 想要的方向、不碰的 | `styles.md` |
| 打理 | 能不能接受手洗、干洗 | `worth.md` |
| 颜色、材质、正式度 | 衣橱里常穿的那几件 | `pairing.md` 的「能搭几套」 |

档案里缺的项，就在结论卡的「依据」里说缺了什么、补上会怎样；不要拿任何「一般人」的身材去顶。

## 标准叫法

属性卡里统一用下面这些词，同一个东西不换着叫；商品页上卖家的叫法不一样时，在括号里注一下原话。分类方式参照 Fashionpedia 的服装本体（品类、部件、属性分开记）。

- **衣长**：短款（到腰）、到胯、盖臀、到大腿、膝上、及膝、膝下、中长（到小腿）、长款（到脚踝）、及地。
- **裙长**：超短、迷你、膝上、及膝、膝下、中长、长款、及地。
- **袖长**：无袖、盖肩、短袖、五分（到肘）、七分、九分、长袖。
- **袖型**：正肩袖、落肩袖、插肩袖、马鞍肩袖、泡泡袖、灯笼袖、喇叭袖、蝙蝠袖、和服袖、荷叶袖。
- **领口**（没有领子的）：圆领、紧口圆领、V 领、深 V、U 领、方领、一字领、挂脖、露肩、单肩、高领、半高领、堆堆领、亨利领。
- **领型**（有领子的）：尖领、八字领、温莎领、纽扣领、伊顿领（圆角小领）、古巴领、一片领、娃娃领、水手领、Polo 领、罗纹领、立领、平驳领、戗驳领、青果领、鱼嘴领、连帽。
- **开襟**：套头、半襟、单排扣、双排扣、拉链、半拉链、按扣、系带、裹身、暗门襟、明门襟。
- **腰线**：高腰、胸下（帝政）、自然腰、低腰、落腰、没有腰线。
- **廓形**：H、X、A、Y、O、I；修身、合身、宽松、oversize；对称、不对称；茧形、斗篷形、荷叶摆。
- **图案**：纯色、暗纹、条纹、格纹（格伦格、苏格兰格、千鸟格、窗格、维希格、塔特萨尔格）、人字纹、鸟眼、波点、碎花、腰果花、几何、迷彩、动物纹、费尔岛、菱格、字母和 logo。
- **工艺和后处理**：水洗、做旧、破洞、刺绣、印花、扎染、绗缝、压褶、抽褶、褶裥、拼接。
- **部件**：领、驳头、肩章、袖、口袋、领口、带扣、拉链、帽子、荷叶边、蝴蝶结、流苏、铆钉、亮片、贴布。
