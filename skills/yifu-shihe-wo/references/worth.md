# 值不值

前三问说的是穿上合不合适，这一问说的是买回来穿不穿得上。不比价，不判断价格高低。

## 看四件事

1. **场合和正式度**：这件能穿去哪？用户一周有几天在那种场合？只适合一年一两次的场合（婚礼、年会），说清楚。这件的正式度（怎么看见 `pairing.md`）要对得上用户要穿的场合：太正式的，看能不能靠搭配降一档；降不下来、平时又用不上，就算穿不上。
2. **能搭几套**：和用户衣橱里常穿的那几件，能凑出几套？
   - 三套以上：✓。
   - 一两套：△。
   - 一套都凑不出，要为它再买别的：✗。这是最常见的「买回来不穿」。
3. **每次穿的成本**：价格 ÷ 预计穿的次数（一季大概几个月 × 每周几次）。只当参考，算个大概，不装精确。
4. **好不好打理**：看面料成分。

| 面料 | 要注意的 |
|---|---|
| 真丝 | 多半要手洗或干洗，怕水渍、怕晒、容易抽丝 |
| 羊毛、羊绒 | 会起球，要手洗或干洗；含量低的混纺起球更快 |
| 亚麻 | 一穿就皱，要能接受皱 |
| 粘胶（人造棉）、莫代尔 | 下水容易缩、容易变形 |
| 涤纶（聚酯纤维） | 好打理，但不透气，夏天闷 |
| TR（涤纶加粘胶） | 能机洗、不变形，适合出差；垂感和质感不如羊毛 |
| 醋酸 | 凉、顺滑、好打理，容易勾丝 |
| 莱赛尔、天丝 | 软、垂顺，容易勾丝、软塌，要低温手洗、不能暴晒 |
| 羊绒大衣、羊绒衫 | 基本只能干洗或小心手洗，一年的护理费可能不低 |
| 棉 | 好打理，纯棉容易皱、容易缩 |

用户嫌麻烦、或者说过「只想机洗」的，要真丝、羊毛这类就给 △。

## 怎么算进结论

值不值一般只做加减：前三问都 ✓、这一问 ✗，结论落「看你怎么穿」，在「还是想买的话」里说要配哪件、或者等有了哪件再买。

只有前三问也有冲突、这一问又是 ✗，才劝退。

## 拿不准的时候

- 做工值不值这个价，看 `categories.md` 里各品类的「做工」。
- 太标志性的潮流单品（大 logo、某一季的爆款元素），过了那一阵容易尴尬，穿着次数按一两季算。
- 外套、包这类贵的大件，网购要防假，能线下试就线下试。
- 收到货试穿时，只要有一点犹豫，就退。
- 提醒先看有没有七天无理由、运费险。
- 收到货在窗边自然光下，贴着脸、站远一点全身各拍一张，再发回来看一次。
