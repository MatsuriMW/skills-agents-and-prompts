# 品牌卡

一件衣服挂在哪个牌子下面，先说明了它大概是给谁做的：哪个性别、多大年纪、什么价位、什么风格。这是**先验**，拿来定个大方向；单品本身读出来的东西（属性卡）和它冲突时，以单品为准。

## 什么时候用

- 每次判断前，从商品页的店铺名、吊牌、领标、logo、商品标题里认出品牌。认得出、表里有的，填一张品牌卡（平时不贴出来，只在结论卡里写一行「品牌」）。
- 用户问「这个牌子怎么样」「这个牌子适合我吗」「这家是给什么人做的」，或者要详版时，把品牌卡贴出来。
- 认不出品牌、是淘宝原创小店、工厂店、白牌的：品牌行写「—　没有品牌先验，只看这件」，不编。
- 表里没有的品牌：能联网就查它官方旗舰店的价格带、主力品类和模特、详情页里写的目标人群，按下面的模板填，标「现查」；不能联网就只写认得出的部分，其余写「看不出」。

## 模板

```
【品牌卡】COS
定位　H&M 集团的中高端线；极简、建筑感廓形
人群　男女 · 主力 25–40 岁 · 城市白领、设计相关行业
价位　中高（T 恤 300–600，外套 1500–3500）
风格　极简、cleanfit（纯色、几何廓形、几乎没有 logo）
常用色　⬛ 黑　⬜ 白　🟫 驼　⬜ 灰 · 低饱和中性色
版型　欧版，整体偏宽松；袖长、衣长偏长
留意　羊毛、羊绒款质感中上；化纤混纺款要看成分
这件　主线基础款，和品牌的方向一致
对你　风格 ✓ 你要的 cleanfit 一路　价位 △ 比你常买的高一档　版型 △ 袖长要看尺码表
```

- **人群**里的年龄是这个牌子主力顾客的大概范围，不是限制，也不拿来评价用户。
- **价位**只说这个牌子定位在哪一档，不比哪家便宜、不报优惠（不比价）。页面上的实际价格和这一档差得远的（奥莱款、清仓、联名溢价），写在「这件」里。
- **常用色**用色卡同一套色块（🟥🟧🟨🟩🟦🟪🟫⬛⬜），说这个牌子惯用的调色板；这件的颜色和品牌惯用色差得远的（比如极简牌子的当季高饱和色），在「这件」里说。
- **这件**：它在品牌里是什么位置——主线基础款 / 当季潮流款 / 联名 / 副线 / 奥莱专供款，以及它是不是偏离了品牌的大方向。偏离时，后面的判断按这件自己的属性卡走。
- **对你**：拿品牌卡对用户档案里的「想要的方向」「不碰的」「常买价位」「年龄段」，各给 ✓ / △ / ✗。档案里没有的项不写，**年龄只用用户自己说的**，不从照片推。

## 品牌卡怎么算进结论

- 结论卡里「品牌」一行只是背景，不单独决定三档。品牌人群和用户对不上（比如用户想要老钱风，这家是街头潮牌），而这件本身是基础款、四问都过，照样可以闭眼入；在「品牌」一行说一句「这家整体不是你的方向，但这件是基础款，不受影响」。
- 品牌先验最有用的地方是**尺码和版型**：欧版、美版、日版的同一个码差得多，同一个牌子不同系列（Slim / Regular / Relaxed）也不一样。先验只用来提醒「这里要看尺码表」，数字还是从尺码表读。
- 品牌先验也用在「更适合你的」：这件不合适时，可以说「同一家的 XX 系列 / 同价位风格更接近你的是 XX 这一类牌子」。不推荐购买链接。

## 价位档

按官方旗舰店的常规价（不算大促），看主力单品：

| 档 | T 恤、衬衫 | 外套 |
|---|---|---|
| 低 | 100 以内 | 300 以内 |
| 中低 | 100–200 | 300–800 |
| 中 | 200–400 | 800–1500 |
| 中高 | 400–800 | 1500–3000 |
| 高 | 800 以上 | 3000 以上 |
