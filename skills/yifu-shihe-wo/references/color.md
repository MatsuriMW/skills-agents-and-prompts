# 颜色和脸

## 先看这件离脸多近

颜色影响的是脸。离脸越近，这一问的分量越重：

| 位置 | 分量 |
|---|---|
| 上衣、外套、连衣裙上半身、围巾、帽子 | 重：决定提不提气色 |
| 外套里面只露出一点的内搭 | 中：面积小，靠领口那一截起作用 |
| 裤子、半身裙、鞋、包 | 轻：几乎不影响气色，只影响整套的配色 |

下装的颜色问题，最多给 △，不因为它劝退。

**看真正贴着脸的是什么。** 外套里面戴了围巾、穿了高领、翻出了衬衫领，贴着脸的是它们，外套的颜色退到第二层。判断外套时说清这一点：「平时不戴围巾的话，贴脸的就是这件的颜色」。

## 看不到脸的时候

镜子自拍常常被手机挡住脸，或者脸在画面外。这时候：

1. 档案里有颜色那一项：用档案，可信度跟着档案走。
2. 没有档案：颜色这一问写「— 看不出来」，请用户补一张：自然光下，这件贴着下巴或者穿在身上拍半身，手机别挡脸。
3. 露出来的脖子、手背、手腕也能看出一点冷暖，但光线一偏就不准，只当参考，可信度最多给「低」。

不要从发型、身形或者整体气质去猜肤色。

## 四个量

人和衣服都看这四个量，**同方向就和谐**：

| 量 | 人看什么 | 衣服看什么 |
|---|---|---|
| 冷暖 | 皮肤底色偏粉偏青，还是偏黄偏桃；金饰还是银饰更显气色 | 颜色里带蓝紫，还是带黄橙 |
| 深浅 | 皮肤、头发、眼睛整体亮还是暗 | 颜色本身亮还是暗 |
| 清浊 | 皮肤透不透、眼睛亮不亮 | 颜色鲜亮干净，还是带灰、雾、旧 |
| 对比 | 头发和皮肤反差大不大（黑发白皮反差大，浅棕发浅肤反差小） | 这件自己的拼色、印花反差大不大 |

面料会改变颜色看起来的样子：粗花呢、人字纹、灯芯绒、麂皮、粗针织表面有颗粒和纹理，同一个颜色看起来更灰、更柔，偏「浊」；府绸、精纺、丝光、亮面皮革表面光滑，颜色显得更干净、更亮，偏「清」。高饱和的颜色做成粗纹理面料，冲突会小一些；柔和的人穿亮面，反光本身就可能抢脸。

光泽也能辨面料：哑光一般比亮面耐看；化纤的光泽从哪个角度看都一样亮，羊毛、羊绒、真丝的光泽随角度变化、有层次。商品有视频或多个角度的图时，可以拿来看。

搭配上的颜色规则（低对比怎么拉开明度、灰色和蓝棕怎么配）见 `pairing.md`。

不用一上来就报季型。用户问「我是什么季型」，给「主要像哪一型、也可能是哪一型」，说清是哪几条依据，不硬判一个。

## 一眼能看出来的

有试衣照、或者用户拿这件贴着脸拍的照片，直接看：

- **合**：脸色均匀，黑眼圈、法令纹不明显，看照片时视线先落在脸上。
- **不合**：脸发黄、发灰、发青，阴影变重，视线先落在衣服上——衣服比人抢眼。

## 常见的冲突和救法

| 冲突 | 现象 | 救法 |
|---|---|---|
| 冷暖相反 | 脸发黄或发灰 | 领口垫一层同方向的颜色（白 T、围巾、项链）；或者把它当下装、当外套敞开穿 |
| 太深 | 浅而柔的人穿大面积黑、深棕，脸显得沉 | 换成炭灰、深蓝这类深而不死的颜色；或领口露浅色 |
| 太鲜 | 柔的人穿高饱和，衣服比人抢眼 | 只占小面积；换哑光面料；或配一件雾感色压一压 |
| 太灰 | 清的人穿灰调、雾调，人显得没精神 | 配一件干净鲜亮的单品，放在靠脸的位置 |
| 对比不配 | 低对比的人穿大块黑白撞色，脸被比下去 | 换成同色系深浅搭；高对比的人穿全身同色雾感，反而平 |

「慎用」不是「不能穿」：离脸远一点、面积小一点、换个面料，多数颜色都能穿。只有这件的主体颜色贴着脸、又救不回来，才进劝退。

## 照片的坑和可信度

这些会让颜色判断不准：

- 室内暖光、灯下偏黄；背光；阴影重
- 手机美颜、滤镜（皮肤磨得很匀、偏白偏粉，往往就是开了）
- 化了妆，尤其是底妆和口红
- 染了头发（只影响对比，不影响皮肤冷暖）
- 商品图调过色

可信度：

- **高**：自然光、没美颜，几条线索指向同一个方向，用户的对照题回答也对得上。
- **中**：照片能用，但有一两项没法排除（灯光、妆、商品图色差）。
- **低**：明显开了美颜或强色光，或者两个方向都说得通。

只看出可能开了美颜、又不确定的，最多给「中」。既没有人的照片、也没有穿衣档案，颜色这一问最多给「低」，结论卡里写清楚。
