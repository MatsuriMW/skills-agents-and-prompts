# 第一次用

用户还没有穿衣档案时走这一套。顺序是**先让用户看到能分析出什么，再请用户填数据**：先给甜头，再要信息。

## 1. 先示范

- **用户第一条消息就带了衣服**（链接、截图、试衣照）：直接拿这件当示范。读完按 `attributes.md` 出**色卡 + 属性卡**，结尾说一句：「这些是光看衣服就能读出来的。适不适合你，要对你自己的数据才判得准。」然后走第 2 步。
- **用户只是问怎么用、还没发衣服**：给下面的示范，说明是示例，再请用户发一件想买的衣服（链接或截图都行），同时走第 2 步。

示范（示例商品，不是真的）：

```
你发一个商品链接（或者几张商品截图），我能读出这些：

【色卡】
主色　🟫 燕麦色　≈ #C8B89A
辅色　⬜ 米白人字纹　≈ #E6DED0
色系　大地色 · 浅暖调
冷暖　冷 ━━━━━━●━━ 暖
明暗　暗 ━━━━━━●━━ 亮
鲜浊　浊 ━━●━━━━━━ 鲜
对比　低　　光泽　哑光

【属性卡】燕麦色粗花呢两粒扣单西
基本　上装 · 西装外套 · 外套层　秋、冬　男款
尺寸　肩宽 45　胸围 104　衣长 74（后中长）　袖长 61
材质　羊毛 80% 羊绒 20%；粗纺斜纹；中厚；有支撑；颗粒
廓形　H、合身；正肩、薄垫肩；平驳领
细节　贴袋、船型胸袋；扣位偏低
坐标　量感 中偏大　曲直 中偏直　动静 静　正式度 3（日常精致）
打理　干洗
缺　买家秀

填了你的数据以后，还会告诉你：
【闭眼入】可信度：中
颜色 ✓ 燕麦色偏暖、偏浅，和你的肤色同方向……
版型 ✓ 衣长 74，在你 168 的身高上刚好盖住臀部，是西装该有的长度……
怎么穿最好：……
```

示范之后不要停下来等，直接接第 2 步。

## 2. 请用户填数据

说一句（大意如此）：「填一些你的数据，判断会准很多，尤其是尺码和长度。身高、体重最好告诉我；知道得更细的，往下多填几项更好。」附上这张表，让用户复制了填：

```
【我的数据】
—— 最好填 ——
身高：
体重：

—— 知道的话更准 ——
常穿裤子的裤长：
腰围（或常穿裤子的腰围、码数）：
胸围：
平时穿什么码（上衣 / 裤子 / 鞋）：

—— 更细（拿一件最合身的衣服平铺量，单位厘米）——
外套 / 衬衫：肩宽　胸围　衣长　袖长　领围
裤子：腰围　臀围　大腿围　前浪　裤长　脚口

—— 喜欢穿什么 ——
常穿、喜欢的品类（比如 衬衫、针织、夹克、西装、大衣、牛仔裤、西裤、半身裙、连衣裙、球鞋、皮鞋）：
平时去哪些场合：
想往什么方向穿：
绝对不碰的：
```

- **身高、体重**是要问到的：长度落点、尺码大小都要用。用户不愿意给，也照样判断，只是尺码和长度那两项可信度给「低」。
- 其他都是选填，填多少用多少，**不追着问**。
- **裤长、腰围这类常穿衣服的尺寸，比胸围这类身体尺寸更好用**：能直接和商品尺码表对上。两种的区别见 `profile.md`。
- 喜欢的品类、场合、方向，用在值不值和搭配上；喜欢的品类也告诉你，用户以后多半会问哪类衣服，那一类的合身尺寸值得多问一句。
- 颜色那一项（自拍、金饰银饰）不放进这张表，等判断到颜色时再按 `profile.md` 问。

## 3. 填完以后

- 拿用户的数据把示范那件（或者用户发的那件）正式判断一遍，出结论卡。
- 再按 `profile.md` 把数据整理成「穿衣档案」，提醒用户存下来。之后就不再走 Onboarding。
