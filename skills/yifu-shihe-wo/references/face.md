# 脸型和领子

领子是离脸最近的一圈线条，看人先看脸，紧接着就看到它。颜色贴着脸管气色（`color.md`），领子贴着脸管轮廓：线条往哪走、和脸的轮廓是不是一路、大小和脸配不配。这里只说怎么看脸型、怎么配领子，不评价长相：没有哪种脸型更好，每种都有顺手的领子。

## 什么时候用

- 衣服贴近脸：上衣、外套、连衣裙、围巾、露出领子的内搭。下装和鞋不看这一份。
- 结论卡里写在气质那一行：贴近脸的单品，要说到领子和脸型。
- 用户只问「这个领子适合我吗」「我是什么脸型」「圆脸穿什么领」：只答这一项。

## 先要一张照片

脸型只从照片看。不问「你觉得自己是什么脸型」（多数人说不准），也不拿斜着、笑着的脸硬判。没有能用的照片，请用户拍一张：

- 正面、平视，手机和眼睛一样高；
- 离脸一臂远以上，或者用 2 倍镜头（近距离的广角会把脸中间放大，轮廓看着更圆）；
- 头发拢到耳后，露出发际线、两腮和下颌线；摘掉眼镜、帽子；
- 不笑，闭嘴放松（笑起来脸颊鼓起，下半张脸看着更宽）；
- 关掉美颜和瘦脸；
- 有条件就在窗边自然光下拍：这一张同时能看颜色（见 `color.md`），一张两用。

拍不了这样的，就用手上有的照片，按下面「照片的坑」降可信度。

## 怎么看

看四样，都看骨骼的轮廓（额头、颧骨、下颌角、下巴）。脸颊上的肉会随时间变，以最近的照片为准。

1. **长宽**：发际线到下巴的长度，比颧骨最宽处的宽度。长比宽多一半左右是中等，明显更长是偏长，接近 1:1 是偏短。
2. **最宽在哪**：额头、颧骨，还是下颌。
3. **下颌和下巴**：圆、方（下颌角明显）、尖。
4. **脖子**：长短（下巴到锁骨的距离），高领、立领要看它。

| 脸型 | 怎么认 |
|---|---|
| 鹅蛋（椭圆） | 长比宽多一半左右，额头略宽于下巴，下颌圆顺 |
| 圆 | 长宽接近，颧骨最宽，下颌圆、看不到角 |
| 方 | 长宽接近，额头、颧骨、下颌差不多宽，下颌角明显 |
| 长 | 长明显大于宽，额头、颧骨、下颌宽度接近 |
| 心形（倒三角） | 额头和颧骨宽，往下收成尖下巴 |
| 菱形 | 颧骨最宽，额头和下巴都窄 |
| 梨形（正三角） | 下颌最宽，额头窄 |

多数人介于两型之间，写「主要像 X，带一点 Y」，不硬判一个。

同一张照片还要看脸的**量感**（五官、骨骼大还是小）和**曲直**（轮廓和五官的线条圆润还是有棱角）。这和 `line.md` 气质里的量感、曲直是同一回事，档案里只记一次。脸型本身带一点曲直（圆、鹅蛋偏曲，方、菱形偏直），但眉眼、鼻梁、嘴唇的线条也算，两样合起来判。

## 领子怎么配

三条规则各管一样，分开看。

### 1. 开口方向管长宽

领口往哪个方向开，视线就往哪走。竖向的（V 领、U 领、敞开的衬衫领、尖领、拉低的拉链）把视线往下拉；横向的（一字领、船领、紧口圆领、高领、堆堆领、宽八字领、立起来的大翻领）把视线往两边撑。

- 脸偏短、偏宽，或下半张脸宽（圆、方、梨形）：竖向的顺。
- 脸偏长（长、菱形）：横向的顺；深 V、长尖领会再往下拉一截。
- 中等（鹅蛋、心形）：两种都行，看下面两条。

### 2. 线条随着脸

领子边缘和领尖的曲直，和脸的曲直同一路就顺：

- 曲的脸：圆领、U 领、青果领、圆角领、伊顿领、软领座、有垂感的面料。
- 直的脸：V 领、尖领、平驳领、立领、方领、挺括的领子。
- 曲直反着（棱角分明的脸配荷叶边、娃娃领；很圆的脸配又尖又硬的大领尖）给 △：领子和脸打架，视线会先落在领子上。

但别**原样重复**下颌：方脸配方领、一字领，圆脸配紧口小圆领，梨形脸配贴着下颌的宽高领，领口的线和下颌平行，等于把下颌的形状再画一遍。用户就想让轮廓更鲜明（比如就想要硬朗），这反而是办法，说清楚就行。

方向和线条打架时，方向管领口的形状，线条管边缘：圆脸要竖向、又要曲线，就是圆角 V、U 领、青果领；方脸要竖向、又要直线，就是 V 领、尖领、平驳领，而不是方领。

### 3. 大小随着量感

领子、驳头、领座、门襟上的扣子和拉链头、项链，大小都跟脸和五官的量感走：

- 量感大：领子大一号，比如宽驳头、大翻领、领座高一点的衬衫领、粗针高领。领子太小，视线全压在脸上，领子显得局促。
- 量感小：小领、窄驳头、细罗纹、精致的扣子。超大翻领、厚围巾会让脸被领子吞掉。

### 脖子

- 脖子短：高领、立领、领座高的衬衫领、紧口圆领会把脖子盖住一截；解开一粒扣、V 领、立领的拉链拉低一点，更顺。
- 脖子长：高领、立领、堆堆领、围巾都撑得住；深 V 会让脖子显得更长。

## 速查

| 脸型 | 顺的领 | 要多花心思的领 |
|---|---|---|
| 鹅蛋 | 大多都行，按量感、曲直挑 | 很少 |
| 圆 | 圆角 V、U 领、青果领、敞开的衬衫领、尖领、窄八字领 | 紧口圆领、高领、堆堆领、一字领、大圆的娃娃领 |
| 方 | V 领、U 领、尖领、平驳领、敞开的立领 | 方领、一字领、很宽的温莎领；软塌的荷叶边、娃娃领 |
| 长 | 圆领、船领、一字领、高领、宽八字领、温莎领、翻领、围巾 | 深 V、长尖领、又窄又深的开口 |
| 心形 | 圆领、U 领、船领、小翻领 | 又深又尖的 V、长尖领（把下巴的尖再重复一次） |
| 菱形 | 圆领、U 领、船领、柔和的翻领、高领 | 很深的尖 V、硬挺的大领尖 |
| 梨形 | V 领、U 领、开领，领口上方简洁 | 一字领、宽的紧口领、贴着下颌的高领 |

- **男装**：衬衫领尖张开的角度就是方向，角度小（尖领、窄八字领）往竖向拉，角度大（宽八字领、温莎领）往横向撑；驳头宽窄、领座高低跟量感走。T 恤、针织在圆领、V 领、亨利领之间挑，照开口方向那一条。
- **救法**：围巾、项链、耳饰、眼镜框算领口的延伸，用同一套规则。领子不顺时，扣子开几粒、拉链拉到哪、围巾怎么系，都能把方向改过来，所以领子的冲突多半是 △，很少因为它劝退。

## 照片的坑和可信度

- 近距离广角：脸中间被放大，显得更圆、更宽；
- 低头拍：下巴变短、额头变大；仰拍：下颌变宽、额头变窄；
- 刘海、长发挡住额头或两腮：看不出最宽在哪；
- 美颜、瘦脸：下颌被削尖，往心形偏；
- 侧光、顶光：阴影能做出下颌角，也能把它抹掉；
- 笑、鼓腮：下半张脸更宽。

可信度：

- **高**：照上面的拍法拍的正面照，四样都看得清；再有一张侧面或半身照对得上。
- **中**：正面照能用，但有一两样看不清（刘海挡住额头、手机离得太近）。
- **低**：明显开了瘦脸、广角近拍、低头或仰头，或者只有侧脸。

可信度低时，领子那一项只给方向（「竖向开口的领子更稳」），不报具体脸型。

## 怎么说

- 说「领口往竖向开，视线往下走」「这道横线和下颌平行」「领子比脸小一号，显得局促」。
- 不说「脸大」「显脸小」「修饰脸型」「瘦脸」，也不说「鹅蛋脸最标准」「完美脸型」。
- 用户自己说「我脸大」「想显脸小」，不纠正用词，用方向和线条回答。
