# 这件衣服适合我吗

发一件衣服、裤子或鞋给 AI，它先把衣服拆成色卡和属性卡，再一项项对你自己的穿衣档案，告诉你合不合适、值不值得买：

- 结论落到「闭眼入 / 看你怎么穿 / 劝退」三档之一，附上可信度；
- 颜色和脸、版型和比例、气质、值不值，四项各说一句，说具体（颜色名、衣长落在哪、能配哪件）；
- 每次都附「还想买的话怎么穿」和「更适合你的是什么」。

男装女装都管。只谈线条、颜色和比例，不评价身材。纯提示词，不带脚本，需要一个能看图的 AI（豆包、Claude 等）。

## 效果示例

贴一个淘宝链接，它先把这件衣服拆成色卡和属性卡：主色、辅色、内胆各取一个色值，标出色系和冷暖、明暗、鲜浊三条刻度；白底主图和特写取出来的颜色差了一截，就提醒「主图调亮过，实物更接近特写」。再拿它对你的穿衣档案，才落到「闭眼入 / 看你怎么穿 / 劝退」。

## 怎么装

- **豆包（电脑客户端）**：左侧「插件·技能·伙伴」→「技能」→ 右上角「+ 添加」，上传这个文件夹的 zip 包。
- **Claude Code 等支持 Agent Skills 的工具**：把整个 `yifu-shihe-wo` 文件夹放进它的 skills 目录。

## 手机上和电脑上怎么用

- **手机上：发截图。** 截主图、尺码表、面料成分（在商品参数里），有买家秀最好。人本来就在购物 App 里，截图最顺手。
- **电脑上：贴商品链接，AI 自己打开读。** 它会去读参数、完整尺码表、详情图里的卖家尺码表和试穿表，还有带图的评价。不过：
  1. 是「贴链接、它打开读」，不是「它去搜商品」：不会自己搜同款，也不比价。
  2. 前提是这个 AI 能操作一个你登录过购物网站的浏览器。实测通过的组合是 Claude Code 加一个能控制已登录浏览器的工具（实测用的是 ego lite）。电脑版豆包能不能这样操作浏览器还没验证过；不能的话，它会直接说「这个链接我读不到」，请你发截图。
  3. 淘宝、拼多多要先在那个浏览器里登录；抖音商城、小红书的商品页实测不登录也能看。一次只开你给的那一个链接，弹出滑块验证就停下来交给你。
  4. 电脑上也可以直接发截图，效果一样。

能不能读链接，看的是有没有一个登录过的浏览器，不是手机还是电脑。

## 第一次用

1. 先示范：发一件衣服（或者问「怎么用」），它先给你看能从一件衣服里读出什么：色卡和属性卡。
2. 再请你填数据：身高、体重最好告诉它；知道常穿裤子的裤长、腰围、胸围更准；再细一点，可以拿一件最合身的衣服平铺量肩宽、衣长、袖长；最后是喜欢穿的品类、常去的场合、想往什么方向穿。都可以不填，只是尺码和长度的判断会没那么准。
3. 它会把这些整理成一张「穿衣档案」，存下来，下次贴回去就不用再填。

## 简版和详版

默认只给一屏的结论卡。说「详细说」，会按色卡 → 属性卡 → 结论卡 → 每一项的依据展开；说「简单说」回到简版。

## 还能这样问

- 「这件显黑吗」「我该拿 M 还是 L」「这个领子适合我的脸型吗」：只答那一项。
- 「这两个颜色选哪个」：先说选哪个，再列两件不一样的地方。
- 「给我这件的属性卡」「这件是什么风格」：只拆衣服，不判断合不合适。
- 发一张模特图说「想买这种」：先判断这种款合不合你，再换算成你该找的衣长、肩宽、领型。
- 替别人看衣服：说「给我女朋友买的」，或者发了一件明显是另一个性别穿的（比如男生发了一条裙子），它会先问一句是给自己还是给别人买；给别人的，就给 ta 单独建一张档案。档案可以存好几张，以后按人判断。

## 不做的事

不出效果图，不做虚拟试穿，不比价，不做全身形象诊断。
