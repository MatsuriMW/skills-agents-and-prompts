# 衣橱入库

Vault 根目录：`/Users/chenchen/Library/Mobile Documents/iCloud~md~obsidian/Documents/马自立`
全部用中文。

## 相关文件
- 衣橱卡片：`穿搭/衣橱/<名称>.md`，一件东西一张卡片
- 卡片模板：`Templates/衣物.md`（frontmatter 字段以它为准）
- 身体数据：`穿搭/身体数据.md`（frontmatter 里是适合用户的**成衣尺寸**区间，用来挑尺码、判断合身）
- 看板：`穿搭/穿搭看板.md`（DataviewJS，读卡片的 frontmatter，**不要改它的代码**）
- 图片统一放 `assets/`，卡片里 `图片:` 写文件名（例如 `图片: 黑色切尔西靴_20260925.jpg`），看板会自己去 assets 找

## 来源
1. **聊天里直接发来**：照片（会话里给的图片路径）或购买链接，可能一次好几件。
2. **Telegram 进日记**：用户用 Telegram bot 发照片，配文带 `#衣橱`。在日记 `日记/YYYY_MM_DD.md` 里长这样：
   ```
   - #衣橱 黑色麂皮切尔西靴 42码 闲鱼 680
   	- ![[file_123.jpg]]
   ```
   一次发多张图时，Telegram 只有第一张带配文，后面几张是紧跟着的独立 `- ![[...]]` 行，也算同一件。
   已经处理过的块，行尾会有 `→ [[卡片名]]`，跳过。

## 每一件的步骤
1. **看清是什么**：用 Read 看图；链接用 WebFetch（淘宝、闲鱼常要登录抓不到，就用链接文字里的标题，再从照片里看）。抓不到也不要卡住，把能确定的先填上。
2. **填 frontmatter**（按 `Templates/衣物.md` 的字段；**不确定的留空，不要猜**）：
   - `类别`：上装 / 下装 / 鞋 / 腰带 / 首饰 / 包 / 配饰，只能是这 7 个之一
   - `子类`：具体品类，如 衬衫、牛仔夹克、西装、布雷泽、M65、毛衣、开衫、大衣、牛仔裤、西裤、工装裤、乐福、德比、切尔西靴、项链、戒指……
   - `风格`：**绅装 / 工装 / 国潮** 三选一（可多选，写成列表）；`细分`：**美式复古 / 阿美咔叽**，不属于就留空。这是用户自己的分类，不要发明新的
   - `层次`（只有上装填）：内搭（衬衫、T恤、polo）/ 中层（毛衣、开衫、背心、马甲）/ 外套（夹克、西装、大衣、风衣）
   - `季节`：列表，从 春 / 夏 / 秋 / 冬 / 四季 里选
   - `颜色`、`材质`（麂皮、翻毛、反绒要写出来，看板雨天会避开）、`图案`（纯色 / 条纹 / 格纹 / 波点 / 豹纹 / 印花……）
   - `品牌`、`尺码`、`价格`、`购入日期`（YYYY-MM-DD）、`链接`
   - 尺寸（cm，成衣平铺尺寸）：`肩宽 胸围 衣长 袖长 领围`（上装）、`腰围 臀围 大腿围 前浪 裤长 脚口`（下装）、`脚长`（鞋）。商品页有尺码表时，按用户买的尺码填那一栏
   - `状态`：在穿（默认）/ 闲置 / 已出
3. **图片**：聊天里发的照片，复制到 `assets/`，文件名用 `<名称>_<YYYYMMDD>.<扩展名>`；日记里的照片本来就在 assets，直接用原文件名。多张图时 `图片:` 写最能看清全貌的那张，其余写进正文 `![[...]]`。
4. **写卡片**：`穿搭/衣橱/<名称>.md`，名称用「颜色 + 品牌/特征 + 子类」，简短，例如 `黑色麂皮切尔西靴`、`RRL 靛蓝 type3 牛仔夹克`。重名时先看是不是同一件（是就更新，不是就加后缀 `2`）。正文：
   ```
   - 备注｜<来源（聊天 / 日记 [[YYYY_MM_DD]]）、合身情况、怎么搭的想法>
   ![[其他图片]]
   ```
5. **合身判断**：拿尺寸和 `穿搭/身体数据.md` 对比，在备注里写一句（例如「肩宽 49，比常穿的 47～48 宽一点，属于落肩」）。**裤长上限 100 是硬线**，超过就提醒要改裤脚。
6. **回写来源**（只对日记来源）：在那条 `#衣橱` 行的行尾追加 ` → [[卡片名]]`，不改动行里其他内容。
7. **等待尝试对账**：如果这件东西在日记里以 `[[等待尝试]]` 的形式出现过（比如之前写过「等待尝试 麦穗乐福」、现在买到了），在卡片备注里链一下那条日记，**不要**去改那条日记。

## 结束时
用两三句话说：入库了几件（名称）、哪些字段因为信息不够留空了、需要用户补什么（最常见是尺码和尺寸）。如果什么都没有，就说没有新衣物，不要编。
