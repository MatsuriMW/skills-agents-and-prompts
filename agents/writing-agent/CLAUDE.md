# 稿子库

这个库只放陈晨（马自立）正在写和写完的稿子：口播稿、视频稿、博客长文。草稿、素材、选题都不在这里。

## 和主库的关系

- **主库**在 `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/马自立`：选题页（`选题/`）、日记（`日记/`）、概念和人物、素材库、风格提示词都在那边。
- 每篇稿子对应主库里一个选题页，选题页的属性 `稿件:` 列着这边的文件路径（相对本库根目录）。主库的「选题台」靠它显示成稿进度。
- 稿子属性里的 `素材:` 记着用到的主库笔记；对应选题页的 `用到的素材:` 是它的反向记录。Obsidian 里的写作模式（第二大脑插件）插入素材时会自动记这两处。

## 在这里写稿、改稿

用 `koubo-writer` skill，它管整条流程：找选题 → 从主库备料 → 定方案 → 按风格提示词写 → 自查 → 存稿并回链选题。要点：

- 素材从主库检索，不凭空写。按意思检索：`python3 ~/.claude/skills/koubo-writer/scripts/sem_search.py "说法一" "说法二"`
- 风格以主库 `写作与创作/口播稿风格提示词.md`（口播）和 `写作与创作/书面语风格提示词.md`（长文）为准，每次重新读。
- 不覆盖已有的稿子，新版本另存（` v2`、` v3`）。
- AI 写的稿子属性里带 `作者: AI 初稿`，他自己改过认领后再去掉。**这个库里早期的稿子很多是 AI 生成的，不要把它们当成他本人的文风样本。**
- 新增或改名稿子后，重跑 `bash "<主库>/scripts/index-obsidian-vault.sh"`。

## 不要做的

- 不要在这个库里建选题页、素材页、日记。
- 不要改主库里的日记和笔记正文（选题页的 `稿件` / `用到的素材` 属性除外）。
