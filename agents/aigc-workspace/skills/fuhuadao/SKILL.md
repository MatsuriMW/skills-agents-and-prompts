# 服化道

目标：让一部 AI 短片里的**人穿什么、脸什么样、手里拿什么、屋里摆什么**都有依据、前后连得上，并且能被生图模型稳定复现。

服化道不是装饰。每一件衣服、每一个道具都要回答一个问题：**它在替故事说什么？**（这个人挣多少钱、在乎什么、今天过得怎么样、和上一场比变了什么。）答不出来的东西就删掉，画面里少一件无意义的东西，模型就少一处漂移。

## 和其他 skill 的分工

| 环节 | 用谁 | 本 skill 交出去 / 接过来什么 |
|---|---|---|
| 剧本 → 节拍、分镜、镜头表 | `cinematic-director` | **接过来**分镜稿 / 节拍表，从里面拆场次和镜号 |
| 本 skill | `fuhuadao` | 服化道总表、造型卡、道具卡、连戏表、锁定段 |
| 角色长相锁定 | `character-sheet` | **交出去**每个角色的「主造型 Look A」，作为设定板里的服装部分 |
| 按模型写生图 / 生视频 prompt | `image`、`video` | **交出去**锁定段，原样拼进每个镜头的 prompt |

`cinematic-director` 的 Mode G（continuity bible）管的是镜头层面的一致性；本 skill 管的是服化道部门自己的东西，更细。两者都用时，以本 skill 的造型卡为准，连戏圣经里引用造型卡的编号即可。

## 流程

### 1. 收料

读这些（有哪个读哪个，不要求齐全）：
- 项目目录 `shorts/<项目>/README.md` 和 `资料/`：剧本、分镜稿、节拍表、规划（主题、色调、时代背景）
- 已有角色卡 `character-sheets/<角色>/prompt.md`：长相已经锁定的，服装不要和它冲突；冲突时问用户以谁为准
- 用户给的参考图：用 Read 看，提取款式、颜色（写成 HEX）、材质

然后确认这四件事，用户没说的**一次性**问完（AskUserQuestion），说「你定」就按合理默认补：

| 事项 | 为什么要问 | 默认 |
|---|---|---|
| 时代与地点 | 决定款式、物件是否穿帮（2022 年的南京和 2008 年的南京不一样） | 从剧本推断 |
| 整体色调 | 服装要和场景色调形成关系（融进去还是跳出来） | 从规划文档读 |
| 写实程度 | 写实 / 风格化 / 动漫，决定材质和做旧写多细 | 写实 |
| 本轮范围 | 全片还是某一幕；只要清单还是连 prompt 一起要 | 全片 + 锁定段 |

### 2. 拆场（breakdown）

按场次过一遍剧本 / 分镜，每场记下：在场角色、时间（第几天、几点）、地点、内外景、天气，以及剧情里**明确提到**或**画面必须出现**的服化道元素。分镜里写到的物件（保温杯、机箱、外卖盒）一个都不能漏。

再标出**时间跳跃点**：隔夜、隔天、隔季、闪回、平行世界。服化道的变化几乎都发生在这些点上。

### 3. 定人物造型逻辑

每个主要角色先写三行，再设计衣服：
- **身份**：职业、收入、住哪、通勤方式（决定买得起什么、穿得了什么）
- **性格和状态**：讲究还是将就、这段时间是在撑着还是在垮掉
- **弧光**：从第一场到最后一场，人变了什么，服化道怎么跟着变（变旧、变乱、变干净、某件东西消失）

设计原则和词表见 `references/design-principles.md`（剪影、色彩关系、材质、做旧、妆发状态、道具分类），设计前按需读对应章节。

### 4. 出四张表

模板：`templates/服化道总表.md`。依次填：

1. **造型卡（Look）**：每个角色每一套衣服一张，编号 `<角色缩写>-A/B/C`。逐件写款式、颜色 HEX、材质、版型、做旧程度，以及「它在说什么」。
2. **妆发卡**：按状态而不是按场次写，比如 `三什-妆1 正常通勤`、`三什-妆2 连续加班第 5 天`、`三什-妆3 第 11 天`。胡子、黑眼圈、发型乱度、皮肤油光、伤痕要写成可量化的描述（「下颌胡茬约 3mm」而不是「有点胡子」）。
3. **道具卡**：分三类——**重点道具**（剧情要用、要特写、会变化的，每个一张卡）、**手持道具**（角色随手拿的）、**陈设道具**（按场景列，决定这个空间像谁的家）。重点道具写清数量、尺寸、状态变化。
4. **场次 × 角色总表 + 连戏表**：每场每个角色穿哪套 Look、哪个妆发状态、拿什么；连戏表专门列会**随时间变化**的东西（外卖盒从 1 个到 12 个、衣服从熨过到皱、指甲变长），写清每个时间点的样子。

### 5. 写锁定段

每个 Look、每个妆发状态、每个重点道具，各写一段**英文锁定段**（多数生图模型对英文更稳），中文对照放在旁边。写法和常见翻车（logo 乱生、配饰消失、颜色漂移、道具变形、穿帮）见 `references/ai-lock.md`，**写之前必读**。

要点：
- 只写看得见的物理事实：颜色、材质、版型、长度、扣子数量、位置。不写「高级感」「复古风」这种形容词。
- 每段末尾固定加一句 `Keep this outfit identical in every shot.`（道具用 `Keep this prop identical in every shot.`）
- 一个镜头的 prompt = 角色锁定（来自 character-sheet）+ 本场 Look 锁定 + 本场妆发锁定 + 出镜的重点道具锁定 + 镜头描述。总表里给出每个镜号该拼哪几段。

### 6.（可选）造型板 / 道具板 prompt

用户要「出图看看」时，给每个 Look 写一张**服装设定板** prompt（平铺 flat lay + 正背面上身 + 面料特写，4:3），重点道具写**道具设定板**（三视图 + 状态变化并排）。只有用户明确说「直接生成」才去调生图工具（如 `chatcut-image-gen`），否则停在 prompt。

### 7. 保存和交付

- 存到 `shorts/<项目>/服化道-v<N>.md`，同一项目迭代用新版本号，不覆盖旧版。
- 服装设定板 / 道具设定板 prompt 多的话，另存 `shorts/<项目>/服化道/` 目录，一个 Look 一个文件。
- 回复里只说：拆了几场、几个角色、几套 Look、几个重点道具；哪些是按推断补的、需要用户拍板；建议下一步（通常是把 Look A 交给 `character-sheet`，或者用锁定段出关键帧）。不要把整份表贴进聊天。

## 规矩

- **不发明剧情。** 剧本没写的东西可以补（那是服化道的本职），但要在表里标「补」，方便用户删。
- **不换脸。** 角色卡里已经锁定的长相、发型，不要因为服装好看去改。
- **不出现真实品牌 logo 和可读文字**，除非剧情需要（比如健康码、站牌），需要时在锁定段里写清楚文字内容。
- **时代穿帮要查。** 不确定某个物件在那个年代、那个城市是否存在（手机型号、地铁闸机样式、防疫物品），就标出来让用户确认，或者联网查。
- 用户本人有服装偏好和分类（绅装 / 工装 / 国潮，美式复古 / 阿美咔叽），给角色设计衣服时可以借用这套词汇，但角色不是用户本人，要按角色逻辑来。
