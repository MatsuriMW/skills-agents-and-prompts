# 杜琪峰导演风格 Skill

Load this file when 用户点名「杜琪峰 / Johnnie To / 银河映像风格」，或当场景需要多人在同一画面里对峙、用前中后三层纵深讲人物关系、长时间凝固后突然爆发，以及江湖规矩和宿命压在人身上的感觉。

> 本地补充模块，不在上游仓库中。

## 一句话镜头 / Lens in one line

几个人在窄空间里站成一个形状，谁都不动，光从头顶压下来，一动就全变了。

Several men hold a shape in a tight space under top light; nobody moves, and the first move changes everything.

## 适用场景

- 帮派、警匪、杀手、兄弟情义这类"一群人各怀规矩"的题材。
- 需要三方或多方对峙的段落：谈判、交接、埋伏、等人、饭桌上的试探。
- 港式城市空间：窄巷、唐楼楼梯间、茶餐厅、大排档、停车场、空旷的夜街、旧公寓客厅。
- 需要"一帧讲清关系"的时刻：谁看着谁、谁挡着谁、谁在谁身后、谁还不知道。
- 不适用：单人内心独白、需要强烈主观情绪的爱情戏、依赖大量对白推进的剧情（改用 [07 伯格曼](07_bergman.md) 或 [09 王家卫](09_wong_kar_wai.md)）。

## 反例：这不是什么 / What this lens is NOT

- 不是迈克尔·曼（[19](19_michael_mann.md)）：同样是夜、犯罪、专业者。曼拍一个人和整座城市的距离，人占画高 8%–15%，背后是地平线；这里拍一群人之间的距离，四五个人挤在同一个窄空间里，背景是墙、门和楼梯，不是天际线。曼的孤独是尺度，这里的张力是几何。
- 不是吴宇森：同样是港产枪战。吴宇森是慢镜芭蕾、双枪、白鸽、抒情配乐，动作本身是舞蹈；这里枪战之前的静止比枪战更长，开火时人几乎不移动，站桩对射，动作是几何被打破的一瞬间，不是表演。
- 不是王家卫（[09](09_wong_kar_wai.md)）：同一座城市。王家卫手持、抽帧、拖影、广角贴脸，画面是破碎的记忆；这里的画面是冷静、清晰、设计过的，机位稳，人物排布像棋盘，情绪藏在不动里。
- 不是莱昂内式对峙：同样是多人对峙。莱昂内用眼睛特写的交叉剪辑拉长时间；这里尽量把整个几何关系放在一个宽画面里，用站位和纵深代替切换，观众自己去看谁先动。
- 不是黑泽明（[04](04_kurosawa.md)）：同样是群像。黑泽明用天气和大动作让空间翻腾；这里天气很少，空间是封闭的，动作是突然的、短的，之后又回到静止。

## 核心风格关键词

群像几何、三层纵深、静止对峙、顶光、光池、窄空间、港式夜街、长镜头调度、无声默契、饭桌仪式、宿命与偶然、冷幽默。

## 叙事方法

- 人物靠规矩和站位定义，不靠台词：谁站在门口、谁背对墙、谁先坐下，比任何对白都清楚。
- 默契是核心：兄弟之间靠一个眼神、一个手势、递一支烟完成交流，不解释。
- 每一场戏的张力来自信息差：前景的人知道、中景的人不知道、背景的人正在走进来。把信息差放进同一帧，而不是剪出来。
- 宿命和偶然并存：一件小事（一颗硬币、一次迟到、一个路过的人）让精心安排的局面失控。
- 暴力之后常常接一段近乎滑稽的日常，比如一起吃饭、一起收拾，冷幽默让残酷更重。

## 镜头语言

- **三层纵深是签名**：前景（肩膀、手、枪口、半张脸、门框）、中景（主要人物）、背景（第三方、正在进门的人、楼梯口）。三层各承担一个叙事信息，而且三层之间有视线或威胁关系。
- **纵深镜头的配比**：大约每 3–5 个镜头放一个三层纵深的重镜头，其余用中景、双人、插入和空镜让画面透气。全片都是三层会让人疲劳，也会让重镜头失去分量。
- 主力 21–35mm 配深焦：在窄空间里用广角把前中后景都收进来，光圈收小，三层都要清楚。50mm 给双人和手部插入，85mm 以上只在远距离窥视时用。
- 机位偏稳：锁定、缓慢横移、缓慢推轨。长镜头常以缓慢横移或推轨穿过空间，一边移动一边"揭"出新的人物层次，让前景物体划过画面。
- 群像站位用几何形：三角、一字排开、环形包围、纵向一列。站位本身就是权力关系的图。
- 对峙时用"冻结"：所有人静止，镜头也静止或极慢地移动，持续时间要长到观众开始不安。
- 框中框：门框、窗框、铁闸、楼梯扶手把人分割开，同一帧里隔出不同的阵营。
- 竖幅（9:16）改写：横向排开的群像几何在竖幅里失效，但三层纵深不放弃。改为竖向叠层：前景压在画面下方（桌面、手、枪口），中景人物在画面中部，背景人物放在楼梯上方、阁楼、门后高处，利用楼梯井、唐楼走廊、电梯口这类本身竖向的空间。竖幅通则见 [`../cinematic-language.md`](../cinematic-language.md)。

## 灯光与色彩

- 顶光是核心：光从正上方压下来，眼窝全黑，看不清眼神。观众读的是身形和站位，不是表情。
- 光池：一盏灯照亮一小块区域，周围全暗。人物走进光里才被看见，走出去就消失，站位和光位要一起设计。
- 有源光：路灯、吊灯、日光灯管、霓虹招牌、车头灯，每个光都要有画面内的出处。
- 夜外景常用钠灯橙黄配冷青暗部；室内常用日光灯偏绿或单盏暖色吊灯。
- 暗部要深，不抬黑。高反差，比例约 8:1 以上，大面积暗里浮着几块光。
- 可以有薄雾或烟让光有形状，但不要默认下雨和满屏体积光；雨只在叙事需要时出现。
- 质感词可从 [`../visual-vocabulary-zh.md`](../visual-vocabulary-zh.md) 挑：顶光、光池、钠灯、crushed blacks、35mm grain。

## 剪辑节奏

- 静和动的强对比：对峙段落镜头长（8–20 秒甚至更长），爆发段落切得很快，爆发之后立刻回到长镜头。
- 能在一个镜头里用走位完成的，就不切。切点主要落在"几何被打破"的一瞬间。
- 慢镜全片最多用一次，只给爆发的那一刻。
- 硬切为主。段落之间可以用一颗安静的空镜（空街、空桌、一盏灯）做呼吸。切点逻辑见 [`../editing-and-assembly.md`](../editing-and-assembly.md)。

## 声音与音乐

- 对峙时音乐退掉，只留环境声：日光灯嗡鸣、远处车声、滴水、呼吸、打火机。
- 配乐简洁，常是一个反复出现的简单旋律（口琴、电吉他、弦乐短句），不做情绪铺陈。
- 枪声要干、要响、要突然，和前面的安静形成落差。
- 对白少而短，很多信息用"没说出口"来传达。声音策略见 [`../sound-and-dialogue.md`](../sound-and-dialogue.md)。

## 人物与表演

- 表情极少，动作小而准：点烟、弹烟灰、整理衣领、把手放进口袋。每个小动作都可能是信号。
- 群体里每个人都有固定位置和固定动作习惯，观众靠这些认人，而不是靠脸。
- 吃饭是仪式：一群人围桌吃饭，座次和夹菜顺序就是等级和关系。
- 视线是调度的一部分：谁在看谁、谁在避开谁，要在分镜里写清楚。

## 可迁移拍摄清单

1. 为这场戏写出信息差：谁知道、谁不知道、谁正在到来，并把三者放进同一帧的前中后景。
2. 画出群像站位图，确认它是一个可以命名的几何形（三角、一字、环形、纵列）。
3. 每 3–5 个镜头安排一个三层纵深重镜头，其余镜头给画面透气。
4. 给每个光源写出它在画面里的出处，确认主光在人物头顶，眼窝落在阴影里。
5. 让对峙的镜头长到观众开始不安，然后再打破。
6. 删掉能用站位或眼神代替的台词。
7. 给每个人一个固定的小动作习惯，并在关键时刻让这个动作变成信号。
8. 规定配乐在哪一秒退掉、在哪一声枪响之后回来。

## 落地示例 / Worked example

控制场景：一个人站在一扇关着的公寓门前，手里拿着打算送出去的东西，犹豫，最后没敲门就走了。

用这个镜头，第一个决定是把"一个人"变成信息差：楼梯上方还有一个人在看着他，他不知道；门里的人其实知道他来了，但没开门。第二个决定是把走廊换成唐楼楼梯间的转角平台，这样前中后三层天然成立，而且竖向也有纵深。

节拍：他走上最后几级台阶，停在门前 → 静止，楼梯上方的人出现在背景 → 门缝下的光熄灭（门里的人关了灯）→ 他把东西放回口袋，转身下楼 → 镜头留在空平台，背景那个人仍然站着，8 秒。

调度：两个镜头。SH1 是三层纵深的重镜头：前景是门框和门缝下的一线光（画面左侧，门框被画框切掉一半），中景是他站在一盏裸灯泡下，顶光让他眼窝全黑，背景是楼梯上方转角处另一个人的身影，站在另一块光池里，看着他。28mm 深焦，锁定，机位在门的斜侧 1.3 米高。这一镜持续 12 秒，只有两个变化：背景的人出现，门缝的光熄灭。SH2 是插入：他的手把东西放回口袋，50mm，2 秒。然后回到 SH1 的同一机位，他走出画面，镜头停在空平台和背景那个人身上。

单镜规格（SH1）：全景 / 28mm / 深焦 / 锁定 / 机位高 1.3m / 前景门框与门缝光、中景人物、背景楼梯上方第二人 / 光：裸灯泡顶光 + 楼梯上方日光灯管 + 窗外钠灯橙，三块光池互不相连；比例 10:1，暗部不抬。

- 弱写法：`a man hesitates at a door, Hong Kong, moody, cinematic, Johnnie To style`——模型会给你一个浅景深的单人中景，背景虚掉，没有第二个人，也没有信息差。
- 强写法：逐层写前景、中景、背景各是什么和看向哪里，写 deep focus，写顶光和光池，写明谁动、谁不动。

SH1 用首帧生成，门缝熄灯和背景人物出现分成两次生成更稳；如果工具支持首尾帧，用"背景无人"和"背景有人"两张关键帧做首尾。见 [`../ai-video-tool-adapters.md`](../ai-video-tool-adapters.md)。
