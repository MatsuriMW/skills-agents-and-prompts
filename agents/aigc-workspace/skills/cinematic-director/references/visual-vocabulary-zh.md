# 画面质感词表（Visual Vocabulary）

写每个镜头的生成提示词时，按 **介质 + 镜头 + 光 + 色彩** 四层叠加，每层挑 1–2 个词。只写 "cinematic" 没用。加粗为英文 prompt 关键词。

## 1. 镜头与光学

| 表达 | 效果 |
|---|---|
| 变形宽银幕 **anamorphic lens** | 椭圆焦外、横向蓝色拉丝炫光、边缘轻微畸变 |
| 老镜头 **vintage lens**（Cooke / Helios 44） | 反差柔、旋转焦外 **swirly bokeh**、怀旧 |
| 广角近拍 **wide-angle close-up** | 透视夸张，压迫、滑稽、不安 |
| 长焦压缩 **telephoto compression** | 前后景压扁，拥挤，适合跟踪、窥视 |
| 浅景深 **shallow depth of field** | 主体突出、背景化开 |
| 深焦 **deep focus** | 前中后景全清晰，纵深调度的基础 |
| 分屈光镜 **split diopter** | 近处和远处两人同时清晰 |
| 移轴 **tilt-shift** | 微缩模型感 |
| 黑柔 **black pro-mist / diffusion filter** | 高光泛柔光，皮肤柔，胶片朦胧 |
| **halation** / **chromatic aberration** / **vignetting** | 光晕 / 色散 / 暗角，减轻数码味 |
| **45° shutter** / **motion blur** | 小快门角度动作顿挫；大角度拖影、梦幻 |

## 2. 介质与胶片

- **35mm film grain**：标准电影颗粒
- **16mm**：颗粒粗，独立电影、纪录感
- **Super 8**：家庭录像、回忆
- **Kodak Vision3 500T**：夜景灯光型，暗部偏青、灯光偏暖
- **CineStill 800T**：光源周围红色光晕，霓虹夜景
- **Kodak Portra 400**：暖柔肤色
- **Fuji Eterna**：低饱和、偏青绿、冷静
- **bleach bypass** 跳漂白：低饱和高反差、金属感，战争 / 犯罪
- **cross processing** 交叉冲洗：怪异偏色、高饱和
- **expired film** 过期胶片、**light leaks** 漏光
- **VHS / early DV / CCD camera**：扫描线、色彩溢出、千禧感
- **Polaroid**、**infrared film**

## 3. 调色

- **teal and orange**：好莱坞商业
- **desaturated / muted palette**：低饱和
- **crushed blacks**（死黑、硬朗） vs **lifted blacks / matte look**（灰雾、复古文艺）
- **split toning**：暗部 / 高光分色，如暗青高暖
- **monochromatic**：整体偏一色（芬奇黄绿、《黑客帝国》绿）
- **blown-out highlights**：梦境、回忆、神圣
- **black and white**：**high-contrast B&W** / **silvery B&W**
- **day for night**：蓝调欠曝的假夜景

## 4. 打光

**光位**
- **three-point lighting**：key / fill / back
- **high-key**（明亮少影） vs **low-key**（大面积暗部，黑色电影）
- **Rembrandt lighting**：暗侧脸颊三角亮区
- **butterfly / paramount lighting**：正上方光，鼻下蝴蝶影，经典女星光
- **split lighting**：半脸亮半脸暗，分裂 / 危险
- **top light**：眼窝全黑。《教父》、杜琪峰核心光
- **under lighting**：恐怖诡异
- **rim light**：边缘亮线，把人从背景剥出
- **silhouette** / **backlit, contre-jour**
- **chiaroscuro**：强明暗对照，卡拉瓦乔式

**光的性质**
- **hard light** vs **soft light**
- **motivated lighting**：光来自画面内的台灯、窗、路灯
- **practical lights**：画面可见光源（霓虹、灯泡、电视）
- **volumetric light, god rays** + **haze / atmospheric smoke**
- **dappled light**：树叶 / 百叶窗光斑
- **negative fill**：加深一侧阴影
- **mixed color temperature**：3200K 钨丝暖 vs 5600K 日光冷

**时间与环境**
- **golden hour**、**blue hour**
- **overcast diffused light**、**harsh midday sun**
- **sodium vapor streetlight**：港片夜戏钠灯橙黄
- **wet asphalt reflections**：雨夜反光
- **neon glow**、**flickering firelight**、**fluorescent green cast**

## 5. 画幅与运动

- 画幅：**2.39:1** 史诗 / **1.85:1** 标准 / **4:3** 复古压抑 / **1:1**
- 运动：**handheld**、**steadicam**、**dolly**、**whip pan**、**snap zoom**（70s 港片、邵氏）、**step printing**（王家卫、杜可风拖影）、**speed ramp**、**locked-off shot**

## 6. 摄影师锚点

形容词不够准时直接点名：
- **Roger Deakins**：干净、剪影、单一光源
- **Christopher Doyle 杜可风**：霓虹、抽帧、手持、高饱和
- **Cheng Siu-keung 郑兆强**：杜琪峰御用，冷暗、顶光、群像调度
- **Gordon Willis**：《教父》，顶光、大面积暗部
- **Emmanuel Lubezki**：自然光长镜头
- **Bradford Young**：极深暗部、低照度柔和

## 示例（杜琪峰式夜戏）

> Deep focus wide shot, three men in a standoff in a narrow Hong Kong alley at night. Single overhead sodium streetlight, hard top light leaving eyes in shadow, wet asphalt reflections, light haze. Shot on Kodak Vision3 500T, 35mm film grain, anamorphic lens, 2.39:1, desaturated with crushed blacks and amber highlights.
