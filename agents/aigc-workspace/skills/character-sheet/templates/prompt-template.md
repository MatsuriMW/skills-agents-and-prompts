【表情写法】
- 所有表情都是克制、自然的低强度表情，像一部收着演的真人电影里的一帧；不是表演练习，不是表情包
- 每一格只改变写出来的那一两处，脸的其余部分保持默认表情；五官比例和特征不变
- 笑时嘴唇合着或只微张；难过时眼睛是干的、最多眼眶微红；惊讶时嘴唇只分开几毫米

【一致性要求】
- 所有画面角色完全一致（脸 / 发型 / 比例 / 服装）
- 不允许风格漂移
- 主展示区域必须最大

【质量要求】
- 8K 级细节
- 材质真实（皮肤 / 布料 / 金属）
- 影视级光影
