# Seedance 2.0 分镜生成器 — 项目说明

## 这是什么？

这是一个 **AI 视频生产工作流工具**，核心目标是：

> **将小说 / 故事文本，自动转化为可在 Seedance 2.0 平台直接使用的多集 AI 视频分镜脚本。**

它把三个 AI 工具串联成一条完整的生产线：

```
故事 / 小说文本
	↓
Claude Code
（剧本 + 分镜生成）
	↓
Nana Banana Pro
（角色 / 场景 / 道具图片生成）
	↓
Seedance 2.0
（视频生成 + 分集衔接）
	↓
	成片输出
```

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 剧本创作 | 将原始故事改编为四幕结构（起承转合），自动生成完整剧本 |
| 角色设计 | 为每个角色生成多角度图片提示词，保证跨集视觉一致性 |
| 分镜生成 | 输出 Seedance 2.0 专用时间轴格式（0-3s / 3-6s / 6-9s / 9-12s / 12-15s） |
| 分集衔接 | 通过尾帧描述 + 视频延长语法，实现各集无缝续接 |
| 素材规划 | 自动按 C/S/P 编号体系分类所有视觉资产，配套图片生成提示词 |

---

## 五步生产流程

```
第一步  剧本开发
		将原始故事改编为四幕结构剧本（起承转合）
		
第二步  素材规划
		创建角色(C)、场景(S)、道具(P)的编号图片生成提示词
		
第三步  图片生成
		使用 Nana Banana Pro 等图像 AI 生成统一风格的视觉素材
		
第四步  分镜脚本
		生成 Seedance 2.0 时间轴格式 Prompt，每集独立一个文件
		
第五步  视频生成
		在 Seedance 2.0 平台逐集生成，用视频延长功能串联各集
```

## 如何使用

在 Claude Code 中调用内置技能：

```
seedance [你的故事描述]
```

例如：

```
seedance  风云中聂风小时候的故事
```

技能会自动引导你完成以下确认：
1. 故事聚焦哪个情节
2. 视觉风格（写实 / 水墨 / 动画 / 电影感）
3. 集数 / 总时长
4. 画幅比例（9:16 竖屏 / 16:9 横屏）
5. 情感基调

确认后自动生成全套文件。

## 输出文件说明

### 剧本文件（`[标题]_剧本.md`）

| 章节 | 内容 |
|------|------|
| 核心梗 | 两字卖点，如"血泪成神" |
| 故事梗概 | 背景 / 冲突 / 主角 / 主线 / 结局 |
| 一句话卖点 | 带情绪的营销钩子 |
| 人物小传 | 每个角色的视觉形象、性格、金句 |
| 剧本大纲 | 起承转合四段节奏 |
| 剧本正文 | △镜头格式完整正文，含对白/OS/VO/闪回/字幕 |

### 素材清单（`[标题]_素材清单.md`）

- **C 系列（C01-C99）**：角色，每角色多角度
- **S 系列（S01-S99）**：场景 / 地点
- **P 系列（P01-P99）**：道具 / 物品

每条提示词格式：`[统一风格前缀]，[详细中文描述]，[技术规格]`

### 分镜脚本（`[标题]_E[XX]_分镜.md`）

每集文件包含三个部分：

```
1. 素材上传清单   → 告诉你把哪张图上传到 Seedance 的哪个槽位
2. Seedance Prompt → 时间轴格式提示词，直接复制粘贴使用
3. 尾帧描述       → 记录本集最后一帧，供下一集续接参考
```

## 系统规则

### 脚本格式规则（强制）

- 每个镜头必须以 `△ ` 开头
- 镜头语言必须具体：景别 + 运镜组合

**景别：** 远景 / 全景 / 中景 / 近景 / 特写 / 大特写

**运镜：** 推镜头 / 拉镜头 / 摇镜头 / 移镜头 / 跟镜头 / 环绕镜头 / 升降镜头 / 希区柯克变焦 / 一镜到底 / 手持晃动

**对白标注：**

| 标注 | 含义 |
|------|------|
| `角色名（os）` | 内心独白 / 画外音 |
| `角色名（vo）` | 旁白，人物不在画面中 |
| `角色名（惊/怒/喜）` | 带情绪的对白 |
| `角色名` | 普通对白 |

**特殊元素：**

| 标记 | 含义 |
|------|------|
| `【空镜】` | 无角色的氛围镜头 |
| `【闪回】/【闪回结束】` | 闪回段落 |
| `【字幕：xxx】` | 屏幕文字 / 标题 |

### Seedance Prompt 格式规则

```
[风格描述]，15秒，9:16竖屏，[整体氛围]

0-3秒：[场景建立] - [镜头运动]，[画面描述]，[氛围]
3-6秒：[主体引入] - [镜头运动]，[具体动作]，[情绪]
6-9秒：[发展冲突] - [镜头运动]，[关键动作]，[细节]
9-12秒：[高潮转折] - [镜头运动]，[情绪爆发]，[视觉冲击]
12-15秒：[结尾余韵] - [镜头运动]，[最终画面]，[留白]

【声音】[配乐] + [音效] + [对白/旁白]
【参考】@图片1 [说明]，@图片2 [说明]...
```

### 视频延长语法（第 2 集起）

```
将@视频1延长15s
```

将上一集视频上传为 @视频1，提示词首行使用此语法，实现无缝续接。

### 平台硬性限制

| 限制项 | 上限 |
|--------|------|
| 每次参考图片 | 最多 9 张 |
| 每次参考视频 | 最多 3 段（总计 15s） |
| Prompt 长度 | 建议 300 字以内 |
| 敏感词 | 会导致静默失败（如"江湖人士"） |

### 质量保证 Checklist

发布前必须确认：

- [ ] 所有 `@图片X` 引用在素材清单中有对应 ID
- [ ] 每集有完整的尾帧描述
- [ ] 时间轴完整覆盖 15 秒
- [ ] 每集有完整情感弧线（开场 → 发展 → 高潮 → 释放）
- [ ] 所有对白正确标注（os / vo / 情绪）
- [ ] 镜头语言具体（避免"镜头移动"等模糊描述）
- [ ] 包含感官细节（视觉 + 听觉 + 氛围）

## 常见问题

**Q：遇到敏感词怎么办？**
Seedance 不会告知哪个词触发屏蔽。用二分法排查：把 Prompt 拆成两半分别测试，逐步缩小范围，找到后换一个表达方式。

**Q：如何保证角色跨集一致？**
为每个角色生成多张不同角度的参考图（C01 正面全身、C02 侧面、C03 特写等），每集分镜都明确指定使用哪张图片，并使用统一的风格前缀。

**Q：视频延长后过渡不自然？**
检查上一集的尾帧描述，在下一集 Prompt 的 0-3 秒中明确描述与尾帧匹配的开场画面。必要时在 Prompt 中加入转场指令，如"画面渐暗，天色从黄昏转为黑夜"。

**Q：Prompt 超过 300 字怎么办？**
拆分为多个简短指令，优先保留核心动作和情绪描述，删去冗余的形容词叠加。清晰 > 冗长。
